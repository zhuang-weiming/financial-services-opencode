## A1. WaveTrend (alpha-engine-v21 口径)

**来源：** LazyBear WaveTrend Oscillator，V21 周线等价参数。

```
ESA  = EMA(close, N1)              # N1 = 50 交易日 (10 周)
D    = EMA(|close - ESA|, N1)
CI   = (close - ESA) / (0.015 * D)
WT1  = EMA(CI, N2)                 # N2 = 105 交易日 (21 周)
WT2  = SMA(WT1, 4)                 # 信号线
```

**关键原则（来自 alpha-engine-v21 SKILL）：**
- WT1 必须用**完整历史**（上市日至今）计算。EMA(N2=105) 需要长上下文才稳定、跨股可比。
- **禁止**截断为"最近 12 个月"。
- 月度值 = 日线计算后按月末采样（**不是**在月线序列上重算）。

**信号逻辑：**
| WT1 区间 | 含义 | LAW-001 动作 |
|---|---|---|
| ≥ +60 | 高动量延续（约 95 分位）| 未来 6 月 median +11~13% |
| -60 ~ +60 | 灰色区间 | **无方向信号** |
| ≤ -60 | 低 WT1 非反转（约 5 分位）| 未来 6 月 median -1.57~-1.81% |

**失效条件（LAW-001）：** (1) 市场结构由趋势型转强反转型；(2) 量化策略集体挤入后拥挤失效；(3) 2020-2026 结构性占优不能外推。

## A2. 技术三维投票

```
趋势维   = sign(EMA12 - EMA26) if ADX(14) > 20 else 0
均值回归维 = -1 if (RSI(14) > 70 or %B > 1) else (+1 if (RSI < 30 or %B < -1) else 0)
量价维   = sign(OBV.diff(10)) if 量比 > 1 else 0
综合     = 趋势 + 均值回归 + 量价   ∈ {-3..+3}
```

**失效条件：** ADX 阈值 20 是经验值；震荡市中趋势维频繁翻转；OBV 对跳空/停牌敏感。

## B1. 蜡烛图（TA-Lib 15 形态）

| 类别 | 形态 |
|---|---|
| 单 K 线 (5) | 锤子(牛) / 倒锤(牛) / 射击之星(熊) / 十字星(中) / 陀螺(中) |
| 双 K 线 (5) | 看涨吞没 / 看跌吞没 / 孕线 / 乌云盖顶(熊) / 刺透(牛) |
| 三 K 线 (4) | 启明星(牛) / 黄昏星(熊) / 三白兵(牛) / 三黑鸦(熊) |

**信号逻辑：** 统计最近 N 根（默认 10）的多空形态数，差值符号为方向。

**失效条件：** 形态在 A 股 T+1 + 涨跌停制度下可执行性受限；需结合成交量确认。

## B2. 缠论（czsc）

**链路：** 原始 K 线 → 去包含 → 分型(FX) → 笔(BI) → 中枢(ZS) → 买卖点。

| 概念 | 定义 |
|---|---|
| 顶分型 | 中间 K 线最高 → 潜在卖点 |
| 底分型 | 中间 K 线最低 → 潜在买点 |
| 笔 | 相邻顶底分型之间的一段走势 |
| 中枢 | 至少 3 笔重叠的价格区间 [ZD, ZG] |

**信号逻辑：**
- 最新为**顶分型** → 当前向上笔可能结束 → 潜在卖
- 最新为**底分型** → 当前向下笔可能结束 → 潜在买
- 价格在**中枢内** → 无趋势（震荡），中枢上下沿为支撑/压力

**API 注意（czsc 0.10.x）：** `ZS(bis)` 返回**单个**中枢对象（非列表）。脚本用"3 笔重叠"手动检测全部中枢。

## B3. 艾略特波浪

**链路：** Zigzag swing 检测（滚动窗口局部极值）→ 交替 H/L 序列 → 5 浪推动匹配 → 斐波那契验证。

**三大铁律：**
1. 浪 2 不破浪 1 起点
2. 浪 3 不是最短推动浪
3. 浪 4 不进入浪 1 区域

**斐波那契关系：**
- 浪 2 回撤浪 1 的 0.5-0.618
- 浪 3 / 浪 1 在 1.0-2.618
- 浪 4 回撤浪 3 的 0.236-0.5

**信号逻辑：**
- `L-H-L-H-L-H`（6 点）→ 5 浪上升完成 → 潜在见顶（卖）
- `H-L-H-L-H-L`（6 点）→ 5 浪下跌完成 → 潜在见底（买）

**失效条件：** 浪的划分主观性强；震荡市中易误判；需大级别（周/月）确认。

## B4. 谐波形态（XABCD）

| 形态 | B 点回撤 XA | D 点回撤 XC | 方向 |
|---|---|---|---|
| Gartley | 0.618 | 0.786 | 反转 |
| Bat | 0.382-0.5 | 0.886 | 反转 |
| Butterfly | 0.786 | 1.27 | 反转 |
| Crab | 0.382-0.618 | 1.618 | 反转 |

**PRZ（潜在反转区）：** D 点附近的汇聚区，反转概率高。看涨形态（D 在底部）→ 买；看跌（D 在顶部）→ 卖。

**失效条件：** 多数时候无匹配形态（正常）；比率容差（±0.10/±0.15）影响命中率。

## C1. SMC / ICT（smartmoneyconcepts）

| 概念 | 含义 | 信号 |
|---|---|---|
| BOS (Break of Structure) | 结构突破 | 趋势延续 |
| ChoCH (Change of Character) | 结构转变 | 趋势反转 |
| FVG (Fair Value Gap) | 公允价值缺口 | 价格回补目标 |
| Order Block | 机构挂单区 | 支撑/压力 |

**信号逻辑：** 方向来自 ChoCH + BOS 确认 + FVG 过滤。看涨 ChoCH/BOS + 看涨 FVG → 多；反之空。

**失效条件：** swing_length 参数敏感；假突破多；需结合成交量确认。

## C2. 一目均衡表（Ichimoku）

```
转换线 Tenkan   = (9H + 9L) / 2
基准线 Kijun    = (26H + 26L) / 2
先行带A SpanA   = (Tenkan + Kijun) / 2, 前移 26
先行带B SpanB   = (52H + 52L) / 2, 前移 26
迟行线 Chikou   = close, 后移 26
```

**信号逻辑（三重过滤）：**
- **强买：** TK 金叉 + 价格在云上方 + 云带 bullish (A>B)
- **强卖：** TK 死叉 + 价格在云下方 + 云带 bearish (A<B)
- 其余 → 观望

**失效条件：** 云内震荡时信号全为 0；前移 26 周期导致近期信号基于旧云。

## 独立性质检（跨算法）

**9 个算法全部基于同一 OHLCV 价格序列** —— 是同一数据的多种变换，**不是相互独立的证据**。

- 高共识度 = "价格结构在某方向清晰"，≠ 预测可靠
- 真正独立验证需：成交量结构 / 资金流向（主力/北向/两融）/ 基本面（估值/盈利）/ 宏观（利率/政策）
- 引用"多算法交叉验证"时必须附此 caveat
