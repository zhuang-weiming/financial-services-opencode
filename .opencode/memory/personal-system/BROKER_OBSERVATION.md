# 券商板块观察指标体系

> 创建: 2026-07-22
> 基于: BT-003回测（"成交量驱动PB修复"假设被证伪后的修正框架）
> 状态: 激活 — 定期检查

---

## 核心认知变更

BT-003回测明确显示：**"成交量放大→券商PB修复→股价2-3倍"的原始假设在2015年后已失效。**

修正后的驱动力框架：

```
过时模型:  成交量 ↗ → 佣金收入 ↗ → PB修复 ↗ → 股价 ↗
            ↓
修正模型:  [市场beta(沪深300相关r>0.93)] + [利率周期] + [监管政策] + [居民存款搬家] 
            → 券商收入/利润改变 → PB修复 → 股价变化
成交量 仅作为 辅助确认信号（不是驱动因素）
```

```

□ 日均成交量 万亿/1.5万亿/2万亿
□ 中信证券PB当前值
□ 两融余额趋势
□ 美债5Y CDS（USGV5YUSAB=R，Investing.com跟踪）。当前~38bp，距50bp减仓线仅12bp。每月检查。
□ 北向资金月度净流入/流出
□ AI板块龙头（中际旭创）季度增速
```
