## 核心认知变更

BT-003回测明确显示：**"成交量放大→券商PB修复→股价2-3倍"的原始假设在2015年后已失效。**

修正后的驱动力框架：

```
过时模型:  成交量 ↗ → 佣金收入 ↗ → PB修复 ↗ → 股价 ↗
            ↓
修正模型:  [市场beta(沪深300相关r>0.93)] + [利率周期] + [监管政策] + [居民存款搬家] 
            → 券商收入/利润改变 → PB修复 → 股价变化
成交量 仅作为 辅助确认信号（不是驱动因素）
```

## 观察指标分级体系

### 第一层：宏观先行信号（提前6-12个月）

| 指标 | 当前值 | 触发值 | 逻辑 | 检查频率 |
|:---|---|:---:|:---|:---:|
| **沪深300趋势** | 待查 | 连续3月站上年线 | 券商Beta>0.93，等大盘先动 | 月度 |
| **10年期国债收益率** | 待查 | 下行突破2.0% | 利率下行降低券商融资成本+提升估值 | 月度 |
| **居民存款搬家速度** | 上半年少增3.19万亿 | 季度少增>1.5万亿 | 资金向非银迁移→部分入市 | 季度（央行数据） |
| **监管政策信号** | — | IPO注册制/做市商/降税 | 政策驱动最不可预测但弹性最大 | 事件驱动 |

### 第二层：券商基本面确认（同步信号）

| 指标 | 观察点 | 关键值 |
|:---|---|:---:|
| **龙头券商PB** | 中信证券当前~1.5x | 突破1.8x → 确认修复启动；突破2.5x → 过热 |
| **券商板块成交占比** | 当前~5-8% | 升至12-15% → 板块主线确认 |
| **两融余额** | 当前~1.8万亿 | 站上2.5万亿 → 散户杠杆加速入场 |
| **券商季度营收增速** | 关注经纪+投行+自营三条线 | 连续2季正增长 → 基本面拐点确认 |

### 第三层：退出信号（预计2026下半年-2027中）

| 信号 | 触发动作 | 优先级 |
|:---|---|:---:|
| **美债CDS（USGV5YUSAB=R）** | ⚠️ **关注**——当前~38bp，距50bp减仓线仅12bp（+32%），需每月跟踪 | 最高 |

## 月度检查清单

每月1日执行以下检查：

```
□ 沪深300月线是否站上/跌破关键位（年线/前高）
□ 日均成交量 万亿/1.5万亿/2万亿
□ 中信证券PB当前值
□ 两融余额趋势
□ 美债5Y CDS（USGV5YUSAB=R，Investing.com跟踪）。当前~38bp，距50bp减仓线仅12bp。每月检查。
□ 北向资金月度净流入/流出
□ AI板块龙头（中际旭创）季度增速
```

## 退出流程（按触发顺序）[2026-07-28 v4 修正]

```
触发1：AI硬件（NVDA）Q/Q增速<10%（已触发于NVDA Q2 FY26 +6%）
  → 减仓AI硬件至50%（NVDA/SMH/半导体ETF）

触发2：AI基础设施（hyperscaler capex）同比转负
  → 减仓AI基础设施敞口（META/AMZN/MSFT的AI capex部分）至30%

触发3：AI云服务（GOOGL Cloud）Y/Y增速降至30%以下
  → 减仓AI云服务（GOOGL）至50%

触发4：Capex/Revenue 比值（任一 hyperscaler）> 400%
  → 减仓AI基础设施/云服务至50%
  → ⚠️ AMZN 391% 已接近阈值

触发5：美债CDS飙至50bp+（⚠️ 当前~38bp [修正：原错写~10bp]，距触发仅12bp）
  → 立即执行：AI所有敞口减仓至20%
  → 仅保留现金+黄金+短债

危机级触发：MSFT 5Y CDS>100bp 或 DXY<95
  → 全面撤离美股，仓位转现金+黄金
```

**减仓触发规则（HYP-006 v4）**: 基于 Capex/Revenue 比值动态触发，无固定时间锚：
- AI 产业链是分层结构（硬件/基础设施/云服务/应用），各层见顶时间窗不同：
  硬件 2026 H2-2027 H1，基础设施 2028-2029，云服务 2029-2031，应用 2030+
- 详见 HYP-002 v4 分层错峰结构 + HYP-006 v4 Capex/Revenue 动态触发
