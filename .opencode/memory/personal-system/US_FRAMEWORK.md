## 〇、框架总纲：从什么变了开始

### 〇.1 范式转换（2024 起的结构性变化）

| 维度 | 旧世界（2010-2023） | 新世界（2024 起） |
|:-----|:-------------------|:-----------------|
| **增长引擎** | 互联网平台 + 移动广告 | **AI 基础设施 + 云服务**（hyperscaler capex 竞赛）|
| **利率环境** | 零利率 / QE | **4.5% 高利率 + 结构性赤字**（债务 120% GDP）|
| **化债机制** | Fed QE 直接购债 | **被动化债**（AI 利润 + 海外资金承接，待验证 HYP-010）|
| **市场结构** | FAANG 消费互联网 | **四大 hyperscaler**（MSFT/GOOGL/AMZN/META）capex 竞赛 |
| **货币信用** | 美元绝对信用 | **长期稀释倾向**（慢速剧本 HYP-028）|

### 〇.2 核心矛盾

```
矛盾一：AI 资本开支的"信仰" vs 收入的"兑现"
- capex 全面加速（MSFT +68.8% / GOOGL +103.3% / AMZN +76.7% / META +46.8%）
- **整体 Capex/Revenue 指标**（v3 修正后取代拆分比值）：AMZN 18.4% / GOOGL 22.7% / MSFT 34.9% / META 35.1% 🔴（**META 真警示红旗，无云对冲**，详见 HYP-016）
- FCF 被压缩：AMZN TTM FCF $1.2B（-95%）
  - 估值依赖 AI 收入兑现；兑现依赖 capex 持续 → 自我强化的闭环，也是最大的脆弱点

矛盾二：被动化债的"需要" vs 通胀/利率的"约束"
  - 化债需要低实际利率，但当前实际利率 +1.5%（反抑制期）
  - 降息 → 通胀回归风险（HYP-028 慢速剧本重启需要）；不降息 → 债务成本累积
  - 这正是"三岔路口"的根源：Fed 降息后 30Y 的方向决定剧本走向
```

### 〇.3 核心 thesis（剧本判定中 — 2026-07-31 用户确认：快/慢剧本均未定论，不预设双轨道）

```
核心 thesis: 美股 2026-2030 的路径**取决于化债剧本判定**。当前处于"三岔路口等待期"，
框架的职责是持续判定剧本（分水岭 = Fed 降息后 30Y），配置随剧本切换，不预设轨道。

  - 剧本 B（慢速·脉冲式金融抑制，HYP-028，基准 50%）：衰退降息 → 负实际利率重启 →
    系统性漂移长期稀释美元债务实际价值 → 持有美股 / AI 利润股 / 黄金的长期逻辑
  - 剧本 C（快速·危机驱动重置，HYP-027，尾部 ~10%）：拍卖 <2.0x / CDS >200bp / 30Y >7%
    → 全面撤离预案（见 §八 8.2）
  - 剧本 D（其他，40%）：政策/政治/尾部事件 → 按常规宏观框架处理
  - 结构背景（任一剧本下成立）：AI 超级周期分层错峰（硬件 2026H2-2027H1 见顶 →
    基础设施 2028-2029 → 云服务 2029-2031 → 应用 2030-2032，全周期 6-8 年，HYP-002 v4），
    但兑现节奏随剧本变化
  - 退出不是时间锚，而是**数据触发**（固定时间锚已被 2027-07-01 教训证伪）
  - 与 A 股框架的本质差异：美股**没有单一执行者**（无国家机器），分析核心是
    **信号体系**（HYP-011 危机分 + Capex/Revenue + NVDA Q/Q），而非对手盘分析
```

## 一、A 股 vs 美股框架核心差异

### 1.1 化债机制的本质区别

| 维度 | A 股化债（"显性化债"） | 美股化债（"被动化债"） |
|:-----|:----------------------|:----------------------|
| 机制 | 地方政府债务互换 + 房贷展期 | 金融抑制（实际利率 < 2%）+ AI 利润 + 海外资金承接（待验证，见 HYP-010）|
| 主体 | 政府行政命令 | 市场机制 + 美联储配合 |
| 速度 | 一次性、显性 | 持续性、隐性 |
| 资金流向 | 显性储蓄→理财/股票 | AI 利润 + 海外资金流入美国资产 |
| 受益者 | 持有 A 股 + 黄金 | 持有美股 + 美元 + AI 利润股 |
| 受损者 | 存款人 | 现金 + 短债 + 长期债券持有者 |
| 节奏可控性 | 高（政府说了算） | 低（依赖 AI 持续 + 美联储配合） |
| 失败风险 | 低（行政命令） | **高（AI 见顶 → 化债中断 → 衰退）** |
| 时间锚 | 2023-2027（化债落地） | **2026-2030（化债持续中）** |

## 八、双剧本 → 配置联动预案

> 当前处于"三岔路口等待期"（双剧本均未启动）。本预案在剧本确认后执行，不做预设性调仓。

## 十、反方章节 In Case We Are Wrong

### 10.1 反方叙事 #1：「AI 不是超级周期，是泡沫」（类比 1999-2000）

- **支持证据：** AMZN 整体指标 18.4%（健康）；**META 35.1% 才是真警示红旗**（无云对冲）；FCF 严重压缩（AMZN TTM $1.2B，-95%）；市场集中度极端
- **反驳：** 2000 年崩盘时**收入未兑现**；当前云收入仍在加速（GOOGL +82% / AWS +28%），AI ARR +123%——收入在兑现，只是 capex 跑得更快；AMZN 整体指标 18.4% 健康不构成泡沫
- **裁决条件（v3 修正）：** **任一 hyperscaler 整体 Capex/Revenue > 35%** **或** **META Capex/广告营收 > 30%** **或** 云服务增速连续 2 季度转负 → 反方成立 → 全面执行 4.2 减仓次序（不等 HYP-011）

### 10.2 反方叙事 #2：「被动化债理论是错的，美元没有稀释倾向」

- **支持证据：** 2022-26 实际利率 +1.5%（反抑制）；"17 年连续抑制"已被用户反证推翻
- **反驳：** 2009-21 确曾发生 13 年抑制（实际利率 <2%）；赤字 6-7% GDP 是结构性事实；制度性买家（LCR/外国央行）仍在
- **裁决条件：** 赤字收窄至 <4% GDP + 拍卖长期 ≥2.5x + TIC 连续 6 个月海外增持 → 化债框架失效 → 美股回归纯周期框架（HYP-027/028 移出活跃假设）

### 10.3 反方叙事 #3：「美元体系突发断裂」（快速剧本立即执行）

- **支持证据：** 30Y 已到 5.20%（2007 年来最高）；债务 120% GDP；拍卖认购倍数可能恶化
- **反驳：** 当前无危机条件（CDS 38bp vs 危机线 200bp；拍卖 2.4-2.6x vs 危机线 2.0x）
- **裁决条件：** CDS >200bp 或拍卖 <2.0x → **不等确认，立即执行 8.2 快速剧本预案**

### 10.4 裁决机制

- 任一反方叙事达到裁决条件 → 框架进入**异常模式**：48 小时内完成框架重审 + 用户确认
- 未达裁决条件前，反方叙事只作为监控项，不改变仓位
- 本机制与 A 股框架 §12 一致：反方不是用来否定的，是用来**预先写好转身的路线**
