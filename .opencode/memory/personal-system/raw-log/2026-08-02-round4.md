## 核心发现（全为确定性数学，基线 2026-08）

### 模型一（↓→↑ 转移）
- 若 (1−c)(1+r)=1，暴跌回本=市值不变，纯粹重新分配。对称拉爆**不降债务**。
- 崩−40%回67%（回本），换手 15% → 转移 **$3T / 11.4% GDP**。

### 模型二（割肉→政府承接）
- 现实 forced 割肉 4–15% → 政府承接 **$1–3T（3–6% GDP）**，远不足 $13T。
- **反向求解：要撬动 43pp/$13T，需全部股权 >50%（38–75%）被强制清仓 = 山崩级去杠杆，不是温和消化。**

### 模型三（123→80 货币化）
- 有机通道断开：基线不可能（爆炸）；1946-74 式（需要**基本盈余−1.4%**）→ **~10 年**；慢剧本（prime=3,g−i=3）**渐近到 100%，到不了 80%**（`d* = 100×prim/(g−i)`）。
- **主约束 = 结构性基本赤字 (+6%)，不是利率。** 与既有发现完全一致（2020-26：primary +6.84 完全主导）。
- 3b 股权承接：政府持仓 20% + 股权 **+113%** → **~6–8 年**（15%/10%/年）覆盖 $13T。但须诚实：股权重估抬"政府资产"，**不直接降 D/G**；仍需政府真卖出/购债 + 名义 GDP 复涨（g_nominal>i）。

## 关键反转（诚实边界）
1. "先拉爆给政府承接"——纯市场再分配只搬运 3–6% GDP 财富，**接不住 $13T 债务**。
2. 股权承接路径（3b）本质 = **名义资产通胀归公**，等于 H-028/H-029"脉冲式抑制+全局货币化"的资产负债表变体——**并没有绕开 primary 约束**。
3. 全是依赖"下一次衰退降息→复启动"——而当前无危机（CDS 38bp/拍卖 2.4–2.6×/30Y 5.18%），H-027 危机前提未满足。
4. 与 memory 一致：政府超规模吃股权在**法律/政治层被阻塞**（FRA Sec 2A、H-020/026 无受益联盟）。
