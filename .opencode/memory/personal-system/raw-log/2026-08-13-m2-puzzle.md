## 2. 钱在哪里：5 个主要去向（基于框架 + 公开数据合理估算）

### 2.1 居民储蓄存款：**约 150 万亿**（最大单一去向，占 M2 ~42%）

- 2025 末居民存款 ~150-160 万亿 CNY
- 当前利率：0.35%（活期）/ 0.95-1.25%（1Y 定期）
- 实际收益几乎为零（远低于 CPI 1.0%）
- **关键：净储蓄 = 居民存款 150T - 居民贷款 82.9T = 67.1T（超额净储蓄）**
- 过去 10 年（2015-2025）居民储蓄从 ~52T 翻 3 倍到 150T，**平均每年多增 10T**（疫情期间 2020-2022 每年多增 14-18T）

### 2.2 房地产（"锁住"的钱）：**约 400-500 万亿**（含居民 + 企业 + 政府土地）

- 2020-2026 期间中国房地产总市值估计 400-500 万亿 CNY
- 占居民总资产 ~60-70%
- 房产已**锁住**：交易量 2024-2026 持续萎缩（一线 -30-40%，三四线 -50%+）
- **这些钱不进入流通** — 房产作为"储值工具"但无法变现为消费/投资现金
- 这是 M2 巨大但**不引发通胀的核心原因**——大量"账面财富"被锁在不动产中

### 2.3 企业活期 + 定期存款：**约 100-120 万亿**（占 M2 ~28-34%）

- M1 中企业活期 ~104 万亿（118.48 - 14.74）
- 企业定期存款 ~30-40 万亿
- **为什么企业账上这么多钱？**
  - 投资意愿弱（产能过剩 + 回报率低 + 房地产下行无投资标的）
  - 预防性储蓄（地缘风险 + 行业不确定性 + 关税）
  - 化债套利（"借低还高" — 借 3% 贷款还 5-6% 旧债）
- 这是 M2 中**最"死"的部分** — 2024-2026 中国非金融企业存款增速 8-10%，但企业贷款增速仅 5% = **企业是净存款方**

### 2.4 财政存款 + 机关团体存款：**约 35-45 万亿**（占 M2 ~10-12%）

- 财政存款（国库）：5-8 万亿
- 机关团体存款（事业单位、社保、公积金等）：30-40 万亿
- **化债置换的核心资金池**：10 万亿专项债置换 = 财政发新债 → 银行买入 → 旧债还本
- 实际流通 = 0（钱从国库直接到银行清算账户 → 再到企业或项目）

### 2.5 银行理财产品 + 货币基金：**约 30-40 万亿**（包含在 M2 中）

- 银行理财（破净新规后规模收缩）：~28-30 万亿
- 货币基金（余额宝类）：~13-15 万亿
- 实际属于 M2（"准货币"）但已"金融化" — 流向债券市场 > 股市

### 2.6 其他：**约 10-15 万亿**

- 外币存款：~1.5 万亿（折 $1.5T）
- 证券公司客户保证金：~2-3 万亿
- 信托产品：~5-7 万亿
- 其他金融机构存款

## 3. 钱为什么"不进入流通"？5 个机制

### 3.1 机制 1：**储蓄率结构性偏高**（60% 净储蓄率）

- 中国家庭储蓄率 ~36%（2024），vs 美国 ~5%、欧元区 ~13%
- 文化因素（"攒钱买房养老"）+ 社会保障不足（医疗/养老/教育需自筹）
- **结果**：每 100 元收入，36 元存起来不花

### 3.2 机制 2：**房地产的"财富幻觉"**（锁定 60% 资产）

- 过去 20 年房价上涨创造"账面财富"
- 居民不卖房 = 账面财富不变成可消费/可投资现金
- 房价下跌后，**更不愿意卖**（"跌了不是亏"心理）
- 房产交易量从 18 亿平米（2021）→ 7-8 亿平米（2025-2026），**流动性冻结**

### 3.3 机制 3：**化债吸金**（10+12 万亿规模）

- 35/134/150/99 号文化债机制
- **10 万亿专项债置换**：政府发新债 → 银行买入 → 旧债还本
- **12 万亿融资平台退出**：政府接管平台债务 → 银行承接 → 平台消失
- **结果**：M2 在银行间"空转"，未进入实体经济

### 3.4 机制 4：**通缩预期 + 提前还贷**（双重压力）

- CPI 1.0%，PPI 0.5%（实际通缩）
- 居民提前还房贷（2024-2025 每年 5-6 万亿）
- 居民不消费、不投资、不买房 → 储蓄"沉淀"
- **结果**：印钞（M2 增 8%）但流通速度下降 → 名义 GDP 增速 4-5% → 实际通胀 0%

### 3.5 机制 5：**货币流通速度结构性下滑**（MV = PY 公式）

- **费雪公式**：M × V = P × Y（M2 × 流通速度 = 价格 × 实际 GDP）
- 中国 V 估算：2020 ~0.55 → 2026 ~0.42（**下滑 24%**）
- 对比：美国 V ~1.7 → 1.5（基本稳定）
- **同样 M2 增速，中国通胀 = 0%；美国通胀 = 3%**（核心差距在 V）

## 4. "中国之谜"的物理解释（类比）

| 比喻 | 解读 |
|:--|:--|
| **"浴缸"** | M2 = 浴缸里的水（C 356.71T），但**出水口**（CPI 涨价）几乎关着 |
| **"水压"** | 货币流通速度 V = "水流动的速度" — 中国 V 大幅下降，水流不动 |
| **"塞子"** | 化债、房产锁定、储蓄率高 = 5 个塞子堵住"水"流出 |
| **"降水"** | 央行印钞 = "降水" 持续，但浴缸已经满，水位不变（不溢出）|

## 5. 为什么 CPI 反而**通缩**而不是通胀？

### 5.1 公式层面

```
名义 GDP = M2 × V
P × Y = M2 × V
P = (M2 × V) / Y
```

- 中国 2026：M2 +8%，V -10%，Y +5% → P = (1.08 × 0.90 × 0.95) - 1 = **-7.7% 实际**
- 但实际 CPI 仅 1.0%（因为 CPI 不完全反映资产价格）
- **核心**：M2 增长 8% 被 V 下降 10% 抵消

### 5.2 CPI 与"真实通胀"的脱节

- CPI 篮子 = 食品 + 居住 + 交通 + 通信 + 教育 + 医疗 + 衣着
- 中国 CPI 不包含**资产价格**（房产、股票、债券）
- 实际"通胀"已经在**资产端**发生（房价跌 = 负资产通胀；股价跌 = 负金融通胀）
- 资产价格通缩 = "看不见的通缩"

### 5.3 三层通缩

| 层级 | 现状 | 反映在 |
|:--|:--|:--|
| **消费品通缩** | CPI 1.0% | 食品价格弱 |
| **生产资料通缩** | PPI 0.5%（刚转正）| 工业品价格 |
| **资产价格通缩** | 房价 -3.7% YoY（新房）| 居民财富缩水 |

## 6. 政策含义

### 6.1 央行"两难"

- 降息 → 存款利率更低 → 居民进一步从存款搬家（流入理财/债基）→ 银行净息差压力
- 降准 → 释放银行间流动性 → 资金空转（无法进入实体）
- 印钞 → M2 已 356.71T，V 持续下滑，"流动性陷阱"

### 6.2 HYP-029 v2 框架的判断

- 中国**不需要担心"恶性通胀"**（V 太低 + 行政控价 + 5 个塞子）
- 反而是**通缩压力持续**（CPI 长期 < 2%）
- 解决路径：HYP-029 v2 "借通胀窗口" — 主动用温和通胀 2-4% 化解债务
