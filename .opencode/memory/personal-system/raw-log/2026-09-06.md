## 09-06 · 金油比（Gold/Oil Ratio）规律性核查（状态：ADD_5WHY / NEW + DATA_CORRECTION）

**核心发现（新认知）：**

1. **金油比的均值回归 ≈ 90% 由油驱动，金几乎不动：**
   - 2008-06→2009-02：比值 +229.8%（金 −2.6%，油 **−70.5%**）
   - 2016-01→2018-06：比值 −52.4%（金 +17.4%，油 **+146.7%**）
   - 2020-04→2022-03：比值 −91.2%（金 +21.7%，油 **+1287.7%**）
   - 2026-01→2026-09：比值 −36.0%（金 **+2.4%**，油 **+59.9%**）
   → **"做多金油比" = "做空油"的伪装说法**。用金做分母不增加信息量，只增加混淆。
2. **没有稳定中枢，中枢在结构性上移：** 1970s-90s 约 10-16［外部知识未验证］→ 2005-2022 约 10-23 → **2025-26 三读数 36 / 76 / 48.5**。机制：金无边际成本上限（存量货币资产，央行购买+债务货币化定价），油有三重天花板（页岩边际成本 $45-65、OPEC+ 剩余产能 4-5mb/d、EV/效率替代）。→ **若 HYP-029（全球同步债务货币化）为主路径，金油比中枢继续上移是其直接推论，而非"回归 15"**。
3. **分布右偏、上无界下有界：** 油可跌至 0 甚至负（2020-04-20 负值）→ 比值无上界（实测 189.4）；反向要让比值到 3 需油 $1,480，历史零先例。→ **"拉大"结构上比"收窄"容易，但实现路径几乎总是油崩。**
4. **当前 48.5 不是"等着拉大"，而是已在剧烈收窄中**：从 2026-01 的 75.8 收窄 36%，8 个月里油 +59.9% / 金 +2.4%。1 月押"金油比继续拉大"者已亏 36%。
5. **与第一问交叉验证**：PPI/SPX 去趋势路径与金油比路径**独立指向同一结论 —— 便宜的是碳氢能源，不是"商品"整体**。

## 09-06 · "金涨→油必涨"命题核查 + 12 个月油价分布（状态：ADD_5WHY / NEW，预测已登记 decision-journal/2026-09-06.md）

**用户命题：** "金价上涨明显，油价也必然要上涨的，对吗？"

**核查结论：❌ 命题的前提与推理链都不成立。**

1. **前提已失效（数据）**：GLD 日线 2026-04-01~09-04 实测——4/17 高点 445.93（金推算 ~$4,861）→ 6/24 低点 365.92（~$3,990，**−18%**）→ 9/4 406.77（~$4,436，**距 4 月高点 −8.8%**）。"金价上涨明显"只描述 1-4 月。**4/17 以来：金 −8.8%，WTI 从 4/7 的 $114.58 → $91.48（−20%）——两者同步下跌。**
2. **无机械传导（量级不对称）**：四次金油比回归中，金分别 −2.6%/+17.4%/+21.7%/+2.4%，油 −70.5%/+146.7%/+1288%/+59.9%。**油的波动量级是金的 5-50 倍**，说"金涨所以油涨"等于用小尾巴摇大狗。
3. **驱动机制不同**：金 = 实际利率 + 央行购买 + 货币信用（**存量**资产，无产能约束）；油 = 供需流量 + OPEC 剩余产能 + 地缘 + 需求弹性（**流量**商品，有边际成本与替代天花板）。唯一共同因子是"美元 + 通胀预期"，而当前两者都不支持油：**广义美元 118.75（偏强）、10Y breakeven 仅 2.35%**。
4. **"金油同涨"只在滞胀/供给冲击 regime 出现**（1973-74、1979-80、2021-22）。当前是"金强油弱"= **债务货币化/避险主导**，不是通胀主导。**若真切换到油主导的通胀 regime，金可能因实际利率上行而下跌**（1980 后先例）——用户想要的"两个都涨"内部存在 regime 冲突。

**Polymarket 隐含分布（2026-09-06，9 月合约）：** 触及 $95=66% / $100=31.5% / $105=15.3% / $110=9.5% / $115=5.75% / $120=2.55% / $130=1.65% / $150=0.95%；下探 $85=60% / $80=34% / $75=16.5% / $70=6.5% / $60=1.25%。伊朗制裁豁免 9/30 前恢复=7%；伊朗开征霍尔木兹通行费 10/31=11.5%、12/31=**27.5%**；美国开征=3.55%；伊朗岛屿失控 9/30=1.95%；委内瑞拉 2026 达 1.7mb/d=3.6%；SPR 9/25 前跌破 280M=**82%**。

**新增机制认知：** 2026 年油价的驱动是**制裁供给冲击**（7/7 撤销 General License X）而非需求扩张——这解释了"油涨 60% 但 breakeven 只有 2.35%"的组合：市场把它定价为**可逆的政治事件**，不是趋势通胀。**含义：HYP-029 的"商品长牛"若靠制裁驱动，其可逆性远高于靠货币驱动**——这是对 HYP-029 证据质量的一次下调（同样的价格上涨，驱动来源决定持续性）。
