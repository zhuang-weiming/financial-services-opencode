**化债杠杆公式**: `Δ(Debt/GDP) ≈ (i - g_nominal) × (Debt/GDP) / 100 + primary_deficit_gdp`

## 3. 核心发现：1946-74 真实机制

### 3.1 数学验证（脚本运行结果）

**1946-74**:
- model_predicted_annual_change = -3.163pp/年
- actual_annual_change = -3.150pp/年
- **verification_error = 0.013pp/年** (近乎完美)

**2020-26**:
- model_predicted_annual_change = +3.829pp/年
- actual_annual_change = +3.833pp/年
- **verification_error = 0.004pp/年** (近乎完美)

**结论**: 公式 `Δ(Debt/GDP) = (i-g_nominal) × Debt/GDP / 100 + primary_deficit` 完全解释了 Debt/GDP 演化。模型验证 100%。

### 3.2 旧 vs 新叙事

| 叙事 | 论点 | 1946-74 真实数据 | 验证 |
|:----|:----|:-------------|:----:|
| **旧** | 化债靠「实际利率负 + 通胀稀释」| 实际利率 = **+1.70%**（正）| ❌ FALSIFIED |
| **新** | 化债靠 g_nominal > i（分母稀释）| g_nominal 7.02% > i 4.72% | ✅ CONFIRMED |

### 3.3 拆解归因

**1946-74**（去杠杆 -88.2pp / 28 年 = -3.15pp/年）:
- Rate effect: -1.72pp/年（g_nominal > i 贡献）
- Primary effect: -1.44pp/年（小幅财政盈余贡献）
- **Rate 贡献 54.7%，Primary 贡献 45.7%**

**2020-26**（加杠杆 +23pp / 6 年 = +3.83pp/年）:
- Rate effect: -3.01pp/年（仍帮去杠杆）
- Primary effect: +6.84pp/年（财政赤字主导）
- **Primary 贡献主导** — 不是 i > g_nominal，而是 primary_deficit 太大

### 3.4 关键洞察

1. **1946-74 不是「金融抑制」**：实际利率为正（+1.70%），靠 g_real = 4%（婴儿潮 + 战后重建）驱动
2. **2026 的真正杠杆**: g_nominal > i 仅 -0.60pp（vs 1946-74 的 -2.30pp，弱 4 倍）
3. **2020-26 加杠杆完全由 primary_deficit 驱动**——**财政赤字是当前债务问题的核心**
4. **完成 -88pp 所需年数**：1946-74 = 28 年，2026 = **~110 年**（速度慢 4 倍）
