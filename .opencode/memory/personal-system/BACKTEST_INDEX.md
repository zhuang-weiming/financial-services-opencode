### BT-001: WT1 极值信号的 forward 收益分布
- **日期:** 2026-07-22 (最近更新: 2026-07-29 P1 衰减重算)
- **执行者:** backtest-builder (subagent)
- **假设:** A 股上 WT1 ≥ +60（高位组）或 WT1 ≤ -60（低位组）的股票，未来 1/3/6 个月 forward 收益的分布特征
- **数据源:** alpha-engine-v21 HDF5 (`data_v20.h5`, Morningstar MCP HS377/HS03W)
- **样本期:** 2010-01-31 → 2026-01-31 (187 月有效 rebalance 点)
- **结果:**
  - 高 WT1 (top 50) 6m mean +22.03% / median +13.00% / p<0.001 / hit-rate 71%
  - 低 WT1 (bot 50) 6m mean +8.09% (被少数 10x 反弹扭曲) / **median -1.82%** / hit-rate 45%
  - Long-Short (H-L) 6m mean +17.03% / median +12.25% / 经 2× TC 后 +16.03%
  - 2020-2026 期间 high-WT1 信号特别强劲 (6m mean +35%, median +27%)
  - **P1 衰减重算 (2026-07-29):** 经 0.33x 衰减后高 WT1 median +11.00%（仍 > 0），低 WT1 median -1.81%（仍 < 0）
- **结论:** **PARTIALLY_SUPPORTED** — A 部分（动量延续）支持，幅度建议从 +13% 下修至 +11~13%；B 部分（低 WT1 反转）不成立（中位数为负），结论更稳健
- **状态:** VALIDATED（数据清晰；经 P1 衰减重算确认方向结论稳健，幅度小幅下修）
- **位置:** `personal-system/backtests/BT-001/`

#### Adversarial Review — BT-001
- **回测最可能出错的方面:** 2020-2026 的结构性牛市在 187 个月中占比 **44.4%**，可能放大高 WT1 信号的表现。P1 衰减重算确认即使极端衰减 0.25x，高 WT1 median 仍在 +9.82%，方向结论不受影响，仅幅度需从 +13% 下调至 +11~13%。
- **最容易被误读的方式:** "高 WT1 买，低 WT1 卖"的简单化——低 WT1 median -1.82% 显示"抄底"完全错误，但很多用户会忽略这个细节只看"高 WT1 mean +22%"。
- **Regime 变化检测:** 如果 A 股转为强均值回复（如 2015 年后的震荡市），高 WT1 的 forward 收益会大幅下降。目前无此信号。P1 衰减重算确认方向结论对衰减系数不敏感。
- **推荐重跑频率:** 每 12 个月（关注 high-WT1 Sharpe 是否衰减；P1 遗留任务：监控 2024-2026 的 OOS 段动量衰减）
- **分拆验证建议:** (1) P2: 用 panel data 做逆概率加权 (IPTW) bootstrap 重算 (2) P3: 按行业分拆（科技 vs 消费 vs 金融的高 WT1 是否不同）
- **5-Why 交叉引用:** LAW-001 的 5-Why Challenge 指出"拥挤效应风险"；P1 衰减重算 (2026-07-29) 确认方向稳健

- **数据源:** baostock / Sina (A 股日线)
- **样本期:** 2015-01 → 2026-07 (约 2800 交易日, 38 folds walk-forward)
- **结果:**

### BT-004: 国家队入市 vs 沪深300走势 【已标记为：方法论错误】

| **要素** | **内容** |
|:---------|:---------|
| **原始假设** | 国家队入市(汇金/证金/PBoC工具)能有效推动沪深300上涨→券商Beta行情 |
| **数据源** | Baostock (CSI300日线4018交易日), AKShare (ETF份额), 公开公告 |
| **样本期** | 2010-01 → 2026-07 (10次事件: 全部为净买入场景) |
| **原始结果** | 10次中7次(70%)1年后正收益，平均+12.8% |
| **原始结论** | **PARTIALLY_SUPPORTED** — 国家队有效托底但非牛市发动者 |

#### ★ 判决：方法论错误 — 已废弃
本回测从设计层面存在**致命方法论缺陷**，其结论不应被引用：

| 缺陷 | 严重程度 | 解释 |
|:-----|:--------:|:------|
| **选择偏差（致命）** | 🔴 致死级 | 10 次事件 **100% 为净买入场景**。无任何净卖出/中性场景的对照组。这相当于"只研究上涨日来证明市场会上涨" |
| **样本量不足** | 🔴 致死级 | n=10 的统计显著性极低。任意 1-2 个事件的加入/移除即可翻转结论 |
| **无对照组** | 🔴 致死级 | 没有对比"如果没有国家队买入，同期市场表现如何"（counterfactual missing）|
| **幸存者偏差** | 🟡 中度 | 可能只记录了"国家队宣布入市"的显性事件，遗漏了隐性托市操作 |
| **归因错误** | 🔴 致死级 | "国家队入市后市场上涨"≠"国家队入市导致市场上涨"——同期可能有其他因素（流动性宽松/政策利好）同时发生 |

**正确的科学设计应满足：**
1. 对比组：国家队未干预时期的同期市场表现
2. 双向分析：净买入事件 **和** 净卖出事件都需要分析
3. 多因子归因：控制流动性/政策/估值的同期变化

**当前状态: DEPRECATED — 不应用于任何分析或决策**

**保留理由（不删除）:** 作为"方法论错误"的案例保留，提醒后续回测必须：(1) 有对照组 (2) 双向分析 (3) 多因子归因。适用于未来 regime 切换回净买入场景时的参考，但引用前必须先重建方法。

### BT-005: 东财分拆验证 — 传统券商 vs 东方财富 PB-成交量关系
- **日期:** 2026-07-29
- **执行者:** backtest-builder (subagent)
- **假设:** 东方财富(300059)作为互联网券商，PB-成交量关系与传统券商本质不同，混入样本扭曲了 BT-003 的结果
- **数据源:** AKShare (stock_zh_a_hist / stock_financial_analysis_indicator_em / macro_china_stock_market_cap)
- **样本期:** 2010-01 → 2026-06
- **结果:**
  - 传统7家 PB vs 全市场成交量: r=-0.30 (p<0.001, 显著负相关) ← BT-003 的 -0.13 被东财正相关拉近
  - 东财 PB vs 全市场成交量: r=+0.26 (p=0.003, 显著正相关)
  - 东财平均 PB 6.54x，传统 1.64x（4×差异）；溢价均值 287%
  - 东财 PB 与传统 PB 仅中度相关 (r=0.41)
  - 分时期: 2015-2020 东财 PB-成交量 r=+0.72(极强)；2020后 r=+0.03(断裂)
- **结论:** **SUPPORTED** — 东财确应被单独建模。剔除东财后传统券商负相关更强(r=-0.30)，BT-003 的 r=-0.13 被东财相反方向的+0.26 所稀释。
- **状态:** VALIDATED（数据清晰，结论稳健）
- **位置:** `personal-system/backtests/BT-005/p0-eastmoney-split-backtest.md`（已从 `out/swarm-analysis-20260729/` 迁移）

#### Adversarial Review — BT-005
- **回测最可能出错的方面:** BPS 从季度财报提取，月度 PB 对 BPS 精度敏感。但东财与传统券商的差异极大（4-12×），不太可能因 BPS 误差反转。
- **最容易被误读的方式:** "传统券商r=-0.30很强→应该做空券商"——错误！r=-0.30 只是历史统计，不能作为交易信号。2020-2026 r=+0.40（正相关），说明关系随时间变化。
- **Regime 变化检测:** 若东财收入结构中基金代销占比下降、经纪占比上升（如监管变化），其 PB 行为可能向传统券商收敛。
- **推荐重跑频率:** 每 12 个月
- **分拆验证建议:** (1) 东财 PB 与基金代销规模(AUM)的时序关系 (2) 东财 PB 与创业板指的 beta 分析

### BT-006: 券商=唯一符合条件的低位蓝海板块？(5项检验)
- **日期:** 2026-08-04
- **执行者:** factor-researcher (subagent)
- **假设:** 用户论点——券商是唯一同时满足(营业优秀/躺平/低估/科技IPO受益/人民币升值受益/无利空)的板块；用于 50%→30% 减仓决策的实证检验
- **数据源:** 申万指数(ak.index_hist_sw) / 行情(ak.stock_zh_index_daily_tx) / 央行汇率(ak.currency_boc_sina) / baostock 个股估值 / 东财主营构成(ak.stock_zygc_em)
- **样本期:** 2015-01 → 2026-08 (T1, 140月); 2016-2026 (T2/T4); 2016-2026 分位 (T3); 2023-2025 年报 (T5)
- **结果:**
  - T1 升值周期: 电子+1.41%/有色+1.25%/通信+0.78%/食品饮料+0.52% 居前; 非银金融 -0.13%; 券商(399975) +0.03% (FX敏感系数0.28弱正); 航空机场 -1.27% 垫底 → "唯一"不成立
  - T2 躺平性: 券商 beta=1.28 alpha=-0.31%/月 波动28.2%; **牛市36月累计超额 -49.55%**(胜率0.31), 震荡市 +28.81%(胜率0.54), 熊市 -7.05% → 高Beta高波动, 不是躺平; 真实风险=牛市机会成本
  - T3 估值: 券商 PE分位 8%/7%(10Y/5Y) 全市场最低梯队, PB分位 19% → 低估成立
  - T4 集中度: 组合A(券商50%+现金50%) beta0.64 vs B(券商30%+保险10%+化学制药10%) beta0.57, 差异仅2pp; 券商最差3月 -18.6% vs 300 -15.9% → 减仓支撑是beta+尾部+牛市跑输, 非组合波动差
  - T5 投行: 2025A利润占比 中金16.9%/建投9.9%/中信5.5%/**中银-2.3%(毛利率-19.3%,亏损)**; 2024寒冬 中信2.7% → 科技IPO红利集中于头部, 中银不构成持仓逻辑
- **结论:** **PARTIALLY SUPPORTED** — "低估"(PE 8%)与"震荡市工具"(+0.65pp/月)成立; "唯一/躺平/牛市受益/科技IPO受益"不成立。减仓 50%→30% 的量化支撑 = 牛市窗口系统性跑输 + beta 1.28 + 中银负毛利投行; 保留 30% 下限 = PE 分位8% + 震荡市超额
- **状态:** VALIDATED（5项检验交叉一致; T1c 稳健性2017-2026 通过）
- **位置:** `personal-system/backtests/BT-006/` (analysis.py / results.json / report-2026-08-04.md / t5_ib_revenue.csv)

#### Adversarial Review — BT-006
- **回测最可能出错的方面:** ①券商用 399975 全行业指数代理, 中银/南京/方正个股 beta 可能偏离 1.28; ②SW二级 证券Ⅱ(801193) 2016-2022 数据空洞(68/22/9行), 无法细分交叉验证; ③汇率用央行中间价非即期, 月度频率降低 FX 敏感度

- **推荐重跑频率:** 每 6 个月 (跟踪 beta 1.28→? 与 PE 分位 8%→?)
- **分拆验证建议:** (1) 个股级 beta/尾部压力测试 (bs_*.csv 已备) (2) 投行弹性因子排序 (中金>建投>中信>>中银) (3) IPO+30%/+100% 情景 EPS 弹性测算
