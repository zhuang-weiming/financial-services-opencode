### HYP-002: AI产业链见顶时间 — 分层错峰结构 + 时间线延长（v4）

- **陈述:** AI 产业链是**分层错峰结构**。各层级见顶时间不同，**全周期时长 6-8 年**（与互联网泡沫同步），不是 2-3 年。

  | **AI基础设施**（capex + 数据中心） | **仍在爆发** | **2028-2029**（不是2027-2028） | AMZN TTM capex $147B（+78% Y/Y）；META capex +100% Y/Y |
  | **AI云服务**（GOOGL Cloud、AWS、Azure） | **仍在加速** ⭐ | **2029-2031**（不是2027-2028） | GOOGL Cloud +82%；AWS +28%（15季最快）；MSFT Cloud +29-40% |

  | **AI企业应用**（Agent、企业级） | **渗透率上升** | **2030-2032+真正爆发** | Fortune 100企业近90%已用Gemini Enterprise版 |

  **关键洞察（基于2026-07-28与用户的深度讨论）：**
  - **互联网泡沫花了5-7年（1999-2005）从硬件见顶（Cisco 2000-03）走到应用层爆发（Google 2005-2007）。AI不应该压缩到2-3年。**
  - AI capex规模是1999年互联网泡沫的5-10倍——更大规模 = 更长回收期
- **关键泡沫指标：整体 Capex/Revenue 比值（详见 HYP-016）**

  - AI需求是**真实的**（MSFT AI ARR $37B、GOOGL Cloud +82%），不是"假需求泡沫"

  | 硬件到谷底 | 2002-10（-90%）| 2028-2029？|

### HYP-016: AI Capex/Revenue 比值是判断泡沫的核心指标（v3）

> **修正说明 (2026-08-04)：** 原使用"AI Capex / Cloud Revenue"拆分比值（AMZN 曾算得 391%），但拆分混淆业务导致误判。修正后以**整体 Capex / 整体 Revenue** 为主指标：AMZN 18.4% / GOOGL 22.7% / MSFT 34.9% / META 35.1%；警示线 35%，META 为真警示红旗（无云对冲）。拆分指标仅作参考。

### HYP-017: US30Y 长端利率是估值压缩独立信号（2026-07-30 新增）

- **陈述:** 30Y Treasury 收益率突破 5.20%（2026-07-29 自 2007 以来最高；单日 +10bp；曲线 bear-steepening）标志着长端"term premium"重定价。持续 > 5.0% 对应 DCF 分母上升 → 美股估值压缩。这是 **HYP-011 6 信号矩阵未涵盖** 的独立风险维度，必须监控 US30Y 作为补充。

- **来源:** 2026-07-29 30Y 单日 +10bp 至 5.20%（CNBC live blog）；TLT -1.65%、TBT +3.71%、SHY 几乎平（曲线 bear-steepening 确认）
- **相关资产:** S&P 500 / Nasdaq（直接受影响）、DXY（间接）、Gold（避险 + 通胀对冲）
- **当前状态:** **UNVERIFIED**（首次记录，需后续 1-2 周趋势确认 + 历史回测）

- **历史阈值定义（参考 1994-2024）:**

  | US30Y 区间 | 含义 | 风险资产历史反应 |
  |:-----------|:-----|:-----------------|
  | 3.5-4.5% | 正常扩张期 | 中性偏多 |
  | 4.5-5.0% | "higher for longer" | 震荡 |
  | 5.0-5.5% | 长端重定价期 | 估值压力上升 |
  | 5.5-6.0% | **强压** | 历史 -10-15% 回撤概率上升 |
  | > 6.0% | **危机级别** | 历史 1987/1994/2022 区间 |

- **关键区分（避免过度简化）—— 4 种驱动力对估值影响完全不同:**

  1. **Term premium 重定价**（最常见，估值压制最大）—— 长端持有者要求更高 yield
  2. **实际利率上升**（Real yield，剔通胀）—— Fed 鹰派 → 风险资产折现率上调
  3. **通胀预期上行**（Breakeven）—— 不一定压估值（黄金受益）
  4. **外国需求下降**（Term premium 子集）—— 直接压长端

- **历史先例:**
  - 1994-95：US30Y > 7% 但 S&P 仍上涨（实际利率未明显上升 → term premium 而已）
  - 2007-08：US30Y < 4% 时 S&P 已大跌（信用利差独立主导，非利率驱动）
  - 2022：US30Y 峰值 ~4.5% + 实际利率 +1.6% → S&P -25%（实际利率主导）
  - 2024-至今：从 4.0% 缓涨至 5.20%+（**当前 regime**）

- **建议监控指标:**
  - **US30Y（主）** —— FRED DGS30 / US Treasury Daily Yield Curve
  - **T10YIE**（10Y breakeven inflation）—— 分解通胀预期 vs real rate
  - **DFII30**（30Y real yield / TIPS）—— real rate 驱动
  - **Term Premium**（ACM model）—— 持有期溢价
