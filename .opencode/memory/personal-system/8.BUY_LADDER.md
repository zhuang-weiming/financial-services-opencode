## 〇、前言：Buy ≠ Sell 的镜像

Sell-Ladder doc-v2.4.1 解决"何时卖"，已有完整的 14 skill 信号矩阵 + 5 动能结束标志 + 3 阶段框架 + 化债 deadline 兜底 + §一·五 LAW-004 三因子触发（Gate A/C 硬 + Gate B 咨询性）。Buy-Ladder 必须解决 sell-ladder 不涉及的 4 个维度：

| 维度 | Sell-Ladder v2.4 | Buy-Ladder v3.4 |
|:---|:---|:---|
| **核心问题** | 动能何时结束 + 三因子是否破裂 | **趋势何时启动 + 价格是否合理 + 信号是否回测验证 + 三因子是否成立** |
| **错误代价** | 踏空（机会成本） | **套牢**（资本损失，可永久）|
| **核心哲学** | 让利润奔跑（不要因为涨多了就卖）| **顺势而为 + 不预测底部**（不要因为跌多了就买）|
| **LAW 依据** | LAW-002（重尾）/ LAW-004（三因子不成立）| **LAW-001**（A 股动量延续）+ **LAW-004（三因子成立）**|
| **决策依据** | 14 skill 信号矩阵 + 5 结束标志 + 三因子不成立触发 | **三因子门控（A/C 硬 + B 咨询）+ 4 信号积分 2/2/1/1 + 绝对阈值**（BT-015/016/017/018/019）|

**LAW-001 是设计的硬约束**：A 股低 WT1 买入 median 为 **-1.82%**（不反转！），高 WT1 买入 median 为 **+11~13%**（动量延续）。

→ **Buy-Ladder 不能设计成"跌深了就买"；必须设计成"动量已起 + 估值/板块/regime 配合时追入"**

## 一、买入哲学 (5 条核心原则)

### 原则 0: 三因子门控是入场券（LAW-004 v3.3 整合 · v3.5 分层）

> **底层公理：** 好股票 = 好公司 ∧ (好价格 at t ∧ 好政策 at t)（LAW-004 v3.3）—— "遇到"= AND 共现
> **入场券规则（v3.5 分层，2026-09-04）:** **Gate A（好公司）∧ Gate C（好政策）为硬约束**——任一子项不达标 → **不进入任何阶段判定**（不论信号矩阵多亮、积分多高、regime 多配合）；**Gate B（好价格）为咨询性**——满足则优先，不满足不阻断（与 LAW-001 动量追入兼容，见 CONFLICT-LAW001-LAW004；极端高估由 5 大否决⑤拦截）
> **优先级：** 这是比 Layer 0 / Layer 1 / 积分 / 否决都更前置的**硬约束（A/C）**——好公司不合格/好政策反转 = 不值得研究它的入场时点
> **与既有规则关系：** 与"不预测底部"并列，是"先选对标的，再选对时点"

### 原则 1: 不预测底部 (Don't Catch the Falling Knife)

- A 股是"动量市场"（LAW-001）—— **低 WT1 反转不成立**
- BT-007 deep-recovery 实证（65 事件）：120d 中位 **-7.82%**, 胜率 **17%**
- **触发条件 ≠ 反转信号**——必须等动量已经启动再追入
- **LAW-004 衔接：** 即使动量起来了，如果"好公司"破裂（造假/管理层失信），仍不买——动量可能是诱多

### 原则 2: 安全边际 (Safety Margin)

- 估值锚定：PE/PB 历史 5 年分位 < 50% OR PEG < 1.5
- 基本面拐点：ROE > 8% + 营收/利润增速 ≥ 0
- 市值门槛：≥ 300 亿（LAW-005 USER_RULE 候选）
- 5 道筛子任一不通过 → 不进入观察池（无论技术信号多好看）
- **LAW-004 衔接（v3.5）:** "好价格"（LAW-004 B1/B2）比"安全边际"（本节）更严格——安全边际只要求 PE/PB < 50%，好价格要求 < 30%；好价格还包含 P/FV < 0.85。**2026-09-04 起好价格标准为咨询性**（满足则优先建仓候选，不满足不阻断——LAW-001 动量追入标的天然难满足 <30% 分位），等待 BT 验证（见 CONFLICT-LAW001-LAW004）

### 原则 3: regime 上下文（v3.1+ 咨询性，非 gate）

- **regime 提供宏观上下文；不构成硬门控**（v3.1 起降为咨询性，结构性牛市下不可靠）
- 3 个观测维度（仅展示参考，不阻断判定链）：
  - 沪深 300 MA60 趋势（>0% 且 > -7%）
  - WIF MCI 象限（Q1进攻/Q2平衡/Q3防御）
  - 国家队 regime（净买入/中性/净卖出）
- **LAW-004 衔接：** regime 是"好政策"的宏观维度（LAW-004 C4）；三因子 gate 通过 = "好政策"在标的层满足，regime = 宏观层是否配合（不参与 gate）

### 原则 4: sell-buyer 闭环 (Loop with Sell-Ladder)

- 已有持仓：sell Stage 1 + 回调买入 → 加仓 20%
- 加仓信号必须由 sell-ladder 判定"强动能期" + 价格回调 ≥ 5% + 量缩企稳
- **优先级 sell > buy**（同标的冲突时永远 sell 优先）
- **LAW-004 衔接：** 加仓前必须重审三因子——若任一因子恶化（即使 SELL_LADDER 判定阶段 1 强动能期），不加仓；SELL_LADDER v2.4 §一·五 三因子不成立触发优先于加仓信号

## 四、积分引擎 + 5 大否决（v3.1）

### 4.1 积分计票（v3.1 —— 替代旧 5 大确认标志）

> **v3.1 变更（2026-08-13）:** 旧"5 大确认标志 3+/5 触发"未过回测验证，被**积分引擎**取代。积分 = 4 个回测验证信号按权重 2/2/1/1 计票，总分 0~6。

```python
BUY_SCORE_WEIGHTS = {'technical_basic': 2, 'alpha_zoo': 2,
                     'candlestick': 1, 'ad_line': 1}   # MAX_BUY_SCORE = 6
score = Σ w·signal (signal ∈ {0, ±1})
```

- 绝对阈值: **score ≥ 4/6 = 击球区**，**≥ 3/6 = 观察区**（BT-016 定案）
- 旧兼容字段 `event_pos`/`trend_pos` 仍输出但不参与计分（`score_buy` 返回结构不变）

### 4.2 5 大否决标志（任 1 触发 = 不买，一票否决）

| # | 标志 | 触发条件 | 为什么 |
|:---|:---|:---|:---|
| ① | **下跌趋势未破** | EMA12< EMA26 + ADX > 25 **且 5 日前 ADX 还更高（未收敛）** | 强下跌趋势的反弹 = 飞刀 |
| ② | **量价背离** | 5d 量比 < 0.7 + 5d 价涨 | 反弹无量 = 假突破 |

- ① 不再要求"ADX>25 方向下"，改为"ADX>25 **且 5 日前更高（未收敛）**"（仍下行 = 不买；EMA死叉但 ADX 收敛 = 接近底部，可观察）

## 五、4 阶段 + 3 模式

### 5.1 4 阶段（v3.1 绝对阈值）

| Stage | 条件 | 动作 |
|:---|:---|:---|
| **1 击球区** | score ≥ 4/6 + 否决 = 0 + 非 ST（全期 α60 +1.26%, 2026 弱市 +4.80%）| **分批建仓 50%** |
| **2 观察区** | score ≥ 3/6 + 否决 = 0 + 非 ST（α60 +1.22%）| **放入观察池** |
| **3 回调买入区** | sell-ladder 判定 Stage 1（强动能期）+ 价格回调 ≤ 5% + 量缩企稳 + 否决 = 0 | **加仓 20%（sell闭环）** |
| **4 禁入区** | score < 3/6 OR 否决 ≥ 1 OR ST 红牌 | **不买** |

> **v3.1 注:** Layer 0 / Layer 1 不再计入阶段条件（仅 ST 红牌硬否决 + 展示参考）。
>
> **v3.4 语义澄清（BT-017/018/019，2026-09-01）:** 上表中"击球区 α60 +1.26%"的正确读法是 **"进入 20-60d 动量持仓的入口 α"**，不是"单点择时 α"。BT-017 首入场事件（n=299）α20 −0.28%/α60 −0.20% 不显著；BT-018 亮灯期（信号持续段）α≈0；BT-019 随机进场对照显示信号时机位于随机分布第 7-10 百分位。**α 住在信号死亡后的 20-60 日漂移。** 执行含义：**买入后必须持有到卖出信号/Conv B 退出，不能预期"买入即涨"**。

### 5.2 3 模式

#### 模式 A: 突破买入（积分击球区）

```
score ≥ 4/6 + 否决 = 0 + 非 ST → Stage 1
  ↓建仓 50%（首次入场，建立底仓）
  ↓
1-2 周 重新评估 → score 持续 ≥ 4/6 或 sell-ladder 转 Stage 1 → 加仓至 80%~100%
```

#### 模式 B: 回调买入（sell-ladder 闭环）

```
已经通过模式 A 持有 80%
  ↓
sell-ladder 判定 Stage 1 持续 + 价格回调 ≤ 5% + 量缩企稳
  ↓
加仓 20%（sell-ladder 闭环信号 = 加仓）
```

#### 模式 C: 禁入（v3.1）

```
score < 3/6 或 否决 ≥ 1 或 ST 红牌 → Stage 4，不买
此时 sell-ladder 正常工作（处理既有持仓）
```

## 六、Buy vs Sell 信号冲突仲裁

### 6.1 4 大冲突场景

| 场景 | Buy 信号 | Sell 信号 | 实际场景 | 仲裁 |
|:---|:---|:---|:---|:---|
| **A. 同标的多空冲突** | 击球区 (Stage 1) | 动能结束 (Stage 3) | 不可能同时触发（条件互斥） | 不存在 |
| **B. 跨标的协同** | 标 X 击球区 | 标 Y 阶段3 减仓 | 加 X、减 Y 同时进行 | **同时执行，标的隔离** |
| **C. 闭环冲突** | 标 X 模式 B 回调买入 | 标 X 阶段 3 减仓 | 卖信号触发时回调买入一定不触发 | **优先级：sell > buy** |
| **D. 时间冲突** | 今天击球区信号 | 今天阶段 3 信号 | 跨日发生（同标的不可能同一天触发两个） | **次日重审** |

### 6.2 场景 A 数学互斥证明

| Buy Stage 1 必要条件 | Sell Stage 3 必要条件 | 是否冲突? |
|:---|:---|:---:|
| EMA12 > EMA26 | EMA12 < EMA26（趋势破坏）| ✅ 互斥 |
| ADX 上升（趋势启动）| ADX 下降（趋势衰减）| ✅ 互斥 |
| 量价共振（底部吸筹）| 量价背离（顶部派发）| ✅ 互斥 |
| 结构完成（三买）| 结构破坏（顶分型）| ✅ 互斥 |
| 否决 = 0 | 动能结束标志 3+ | 部分重叠（量能背离）|

**唯一真正的边缘冲突是量能背离**——仲裁规则：**看 60d 趋势方向**——60d 趋势向下 → 适用 buy 否决②；60d 趋势向上 → 适用 sell 结束③。

### 6.3 双向打分矩阵（一个标的上的"全局视角"）

| 维度 | Buy 视角 | Sell 视角 | 综合判定 |
|:---|:---|:---|:---|
| 已持仓 + buy 击球区 | ➕ 加仓 | ➖ 持有（让利润奔跑）| **加仓 20%** |
| 已持仓 + sell 阶段 1 | ➖ 不加仓 | ➕ 持有 100% | **持有不动** |
| 已持仓 + sell 阶段 3 | ❌ 全部清 | ❌ 大幅减仓 | **减仓 80%** |
| 未持仓 + buy 观察区 | ⚪观察 | ➖ 不适用 | **放入 watchlist** |
| 未持仓 + score ≥ 4/6 击球区 + 否决 0 + 非 ST | ➕ 建仓 | ➖ 不适用 | **建仓 50%（v3.1 积分击球区）** |
| 未持仓 + score 3/6 观察区 | ⚪观察池 | ➖ 不适用 | **观察，不建仓** |

**6 种组合全部有明确动作——buy 和 sell 不冲突，而是互补**。

## 六·五、LAW-004 三因子门控（v3.3 重写 · v3.5 Gate B 咨询性）

> **状态：** USER_RULE → LAW 候选（未做 BT 验证，2026-08-30）。**v3.5（2026-09-04）：Gate A 与 Gate C 为前置硬约束**——任一子项不达标 → 直接禁入；**Gate B 降为咨询性**（经验阈值待 BT，不构成禁入；与 LAW-001 动量追入的空集问题见 6.CONFLICTS.md CONFLICT-LAW001-LAW004）。
>
> **核心语义（v3.3）：** 好股票 = 好公司 ∧ (好价格 at t ∧ 好政策 at t)。"遇到" = 时点上三因子共现，是 AND 语义不是加权补偿。详细定义见 `1.LAWS.md` LAW-004。

### A. 三因子门控规则（v3.5 分层）

```
Gate A 好公司 = (A1 ≥ 3.0) ∧ (A2 ≥ 3.0) ∧ (A3 ≥ 3.0)    # 硬约束（公理）
Gate C 好政策 = (C1 ≥ 3.0) ∧ (C2' ≥ 3.0) ∧ (C3 ≥ 3.0) ∧ (C4 ≥ 3.0)  # 硬约束（候选执行）
                # C2' = "无 HYP 标'风险'"（负面清单）
Gate B 好价格 = (B1 ≥ 3.0) ∧ (B2 ≥ 3.0)                  # 咨询性（2026-09-04 起不 gate，待 BT）

Gate A 或 Gate C 任一不通过 = 禁入
Gate B 不通过 ≠ 禁入（计入总分软分；极端高估由 5 大否决⑤拦截）
A/C 通过（Gate B 通过与否不阻断）→ 进入 Layer 0/1 + 积分判定
```

**子项硬门槛细节**（与 LAW-004 一致）：

- **Gate A 好公司（硬）**：A1 ROE 5Y > 行业 median ∧ 经营现金流/净利润 > 0.8 ∧ D/E < 行业 median；A2 主营占比 > 70% ∧ 集中度 < 30% ∧ CR3/5；A3 无重大违规 ∧ 3 年任期 + ROE 任期内提升 ∧ 分红率 > 30%
- **Gate B 好价格（咨询性）**：B1 PE/PB 5Y < 30% 分位 ∧ P/FV < 0.85；B2 DCF 折价 > 30% **或** Graham 数 > 10%
- **Gate C 好政策（硬）**：C1 不在打压名单；C2' 无 HYP 标"风险"；C3 不在监管打压期；C4 G2 默契稳定 ∧ 汇率无急贬

### B. 通过门控后的判定流程

```
Gate A（硬）∧ Gate C（硬）通过（Gate B 咨询性，不 gate）
       ↓
Layer 0 (咨询) + Layer 1 (咨询)
       ↓
ST 红牌（硬否决） → 5 大否决（任一触发 = 不买）
       ↓
4 信号积分（2/2/1/1）：
   ≥ 4/6 击球区 → 进入阶段判定
   ≥ 3/6 观察区 → 放入观察池
       ↓
阶段动作（建仓 / 观察 / 禁入）
```

### C. 通过所有判定后：总分辅助建仓幅度

> **总分不再是门控**——Gate A/C 已是硬约束，总分仅用于通过全部判定后决定分批建仓幅度（Gate B 子项仍计入总分作为软分）。

```
总分 = (avg(A1+A2+A3) + avg(B1+B2) + avg(C1+C2+C3+C4)) / 3

总分 ≥ 4.5 → 60% 建仓（强信号标的）
总分 3.5-4.5 → 40% 建仓（标准建仓）
总分 3.0-3.5 → 25% 建仓（保守，刚过门控）
```

**注意：** 总分仅作为辅助决策，**不参与 gate 判定**。门控已确保 A/C 都达标；Gate B 为咨询性（不满足不阻断入场，但会在总分中拉低建仓幅度）。

### D. 三因子快速判断（库外标的）

> 库外标的扫一眼是否值得深入研究时，可用以下快速判断（Gate A/C 任一答"否"= 对应 gate 失败 = 禁入；**Gate B 为咨询参考**，不满足仅提示"价格不便宜，可等回调或降级观察"）：

**Gate A 好公司快问：**
- 这家公司是否在所属细分行业 CR3/CR5？
- ROE 5Y 均值是否 > 行业 median？
- 最近 3 年是否有重大违规/造假/管理层失信？

**Gate B 好价格快问（咨询性）：**
- PE TTM 在 5Y 历史分位是否 < 30% 且 PB 同样 < 30%？
- Morningstar P/FV 是否 < 0.85？
- Graham 数（股息率 + 增长率）是否 > 10%？

**Gate C 好政策快问：**
- HYP 台账是否有标"风险"？（C2' 硬门槛）
- 所属行业是否在国家战略打压名单？
- 当前监管周期是否处于打压期？

### E. 完整执行流程图

```
                 ┌─────────────────────────────────────┐
                 │ LAW-004 门控（v3.5 分层）             │
                 │   Gate A（硬）∧ Gate C（硬）          │
                 │   任一失败 = 禁入                     │
                 │   Gate B（咨询性，不 gate）            │
                 └─────────────────────────────────────┘
                              ↓ (A/C 通过)
                 ┌─────────────────────────────────────┐
                 │ Layer 0 + Layer 1（v3.1 咨询性）      │
                 └─────────────────────────────────────┘
                              ↓
                 ┌─────────────────────────────────────┐
                 │ ST 红牌 + 5 大否决（v3.1 硬约束）     │
                 └─────────────────────────────────────┘
                              ↓
                 ┌─────────────────────────────────────┐
                 │ 4 信号积分（v3.1 BT-015/016 定案）    │

                              ↓

```

**核心思想：**
- **三因子门控（A/C 硬 + B 咨询）= 选什么**（标的本身——是否值得买入；B 门满足则优）
- **Layer 0/1 + 积分 = 何时买**（市场配合 + 信号触发）
- **总分 = 建仓幅度**（已通过所有门控后的精细决策）
- 三者**顺序串联、维度正交**

### F. 与 SELL_LADDER 三因子不成立触发的衔接

- 加仓（已有持仓 + 回调买入）前必须重审三因子——**Gate A/C 任一恶化**（即使 SELL_LADDER 判定阶段 1 强动能期），**不加仓**；Gate B 咨询（估值变贵不单独阻断加仓，与 SELL 动能叠加判断）
- SELL_LADDER §一·五 三因子触发**优先于 BUY_LADDER 加仓信号**——Gate A/C 不成立 = 必须先执行减仓，不允许反向加仓（Gate B 破裂按 SELL 侧咨询性处理）
- 已持仓标的的月度健康度扫描：每月底对持仓跑一次三因子门控，发现 Gate A/C 失败即触发 SELL_LADDER 流程（详见持仓健康度复审章节）

## 十·五、回测语义澄清 — BT-017/018/019 实证结论（v3.4, 2026-09-01）

> **目的：** 三轮回测回答了一个 v3.3 未明确的问题——**击球区信号到底赚的是什么钱？** 答案深刻影响执行纪律。

### A. α 位置定位（最重要）

| 口径 | 回测 | 结果 | 结论 |
|:---|:---|:---|:---|
| 首入场 + 固定 20/60d | BT-017 | α20 −0.28% / α60 −0.20%（n=299，不显著）| **进场时点无择时 α** |
| 信号持续期持有 | BT-018 | 亮灯期 α ≈ 0（信号持续段仅 2-3 天）| **信号亮着本身不产生 α** |
| 重复事件口径 | BT-016+BT-018 定位 | **α60 +1.26%**（t=4.12，复现 ✓）| **α 住在信号死亡后的 20-60 日漂移** |
| 随机进场对照 | BT-019 | V5 时机在随机分布 7-10 百分位 | 进场时机是负资产 |

**执行含义（写入纪律）：**
1. **买入后必须持有到卖出信号/Conv B 退出**——α 在持有期产生，不在进场瞬间
2. **不要因为"买入后没立刻涨"就怀疑系统**——那是正常的（α 是 20-60d 累计）
3. 击球区的角色 = **"进入动量持仓的入口"**，不是"聪明买点"

### B. "仓位=信心"8 因子缩放：否决（不落地）

| 口径 | 结果 |
|:---|:---|
| BT-017 首入场口径 | V4（8 因子）Sharpe 0.435/0.491 < V1 均匀 50% 0.469/0.508 → REJECTED |
| BT-018 持续期口径 | V4 Sharpe 0.536 vs V1 0.380（方向性），但事件级 bootstrap 95% CI 含 0 → 不确立 |

**负资产因子（两口径皆负，剔除）：** f7_regime（MA60）——2025 牛市绿灯放大负 α，2026 弱市红灯缩小正 α，方向与真实 α 分布相反。
**正贡献因子（BT-017 口径）：** f1 信号强度 + f6 趋势质量（简化 2 因子 V6 有边际优势，bootstrap 96%，但 95% CI 含 0）。
**结论：** 保留均匀仓位默认；若未来演进，只用"信号强度 × 趋势质量"2 因子，且需深熊样本确认。**基本面（ROE/负债）不参与仓位计算——新赛教训的量化证实。**

### C. 强制 Conv B（诚实 T+1 退出）

- **规则：** 信号死亡次日卖出（`exit = score < 阈值 或 end_count ≥ 1 的下一交易日`），禁止前瞻退出
- **为什么：** BT-018 证明诚实 T+1 退出（吸收系统性次日均值回复 raw −0.23%/日）使 Sharpe 比前瞻版**减半以上**（V1: 0.380 vs 1.776）
- **生产回测/评估必须用 Conv B**；Conv A（前瞻）仅作上界参考

### D. 新协议：所有组合级回测必须附随机进场对照

- **教训（BT-019）：** BT-017 的 V5 Sharpe 0.839 是幸存者伪影（`dropna(alpha20,alpha60)` 剔除了 2026-05-15 后全部事件，含 7 月暴跌段）；全保留复算仅 0.476
- **规则：** 任何组合级回测，除目标策略外，必须跑"同事件数×同持有×同仓位"的随机进场对照 300 次，报告目标策略的百分位位置。**无对照的 Sharpe 降权引用**

### E. 待验证方向（不列为生产）

| 候选 | 假设 | 状态 |
|:---|:---|:---|

## 十三、v1.2 修订 — 刻舟求剑问题系统分析（2026-08-11）

### 13.1 问题陈述

> **用户的反驳**："对于不同的行业，不同的市值的股票，对应的 sweet zone 的数值区间是不同的。你需要面对的是 A 股，美股全体市场中的所有股票，用死的数值来衡量所有的股票，会不会死刻舟求剑？"

**这是 buy-ladder 最核心的鲁棒性问题**。v1.1 用了多个静态阈值（WT1 [20, 40]、ADX > 20、5d ret > +2%、HV pct > 70 等），**这些数值在不同行业、不同市值、不同市场的股票上完全不通用**。

#### 刻舟求剑的 5 个具体例子

| 阈值 | v1.1 设定 | 在 A 股银行股 | 在 A 股小盘科技 | 在美股 NVDA |
|:---|:---|:---|:---|:---|
| **WT1 sweet zone [20, 40]** | 静态 | 工行/建行 WT1 几乎从不达 +40，触发率 < 5% | 中际旭创 WT1 周内波动 ±60，触发率 > 50% | NVDA WT1 波动幅度类似中际旭创 |
| **ADX > 20** | 静态 | 银行 ADX > 20 较少，触发频率稳定 | 小盘股 ADX > 20 频繁，触发频繁 | 美股大盘股 ADX > 20 频繁（趋势多）|
| **5d ret > +2%** | 静态 | 银行 5d ret > 2% 罕见 | 小盘科技常态 | 美股大盘股 5d ret > 2% 不罕见 |
| **HV pct > 70** | 静态 | ✅ 已是百分位，相对安全 | ⚠️ 百分位对小盘股历史分布敏感 | ✅ 美股也用百分位 |
| **位置 < 30% / > 80%** | 静态 | 银行 20 日区间窄，30% 阈值不适用 | 小盘股 20 日区间宽，80% 阈值不适用 | 美股类似小盘股 |

**结论**：v1.1 的 5 个静态阈值在不同子群体上有 **0.5×-3× 的触发频率差异**，等价于 buy-ladder 在不同股票上有不同的"门槛严格度"。这是 v1.0 之后第二个必须修订的根本问题。

### 13.2 解决方案：每只股票自身的分位数阈值

**核心原则**：

> **对于每只股票，用它自己过去 252 天的指标分布来定义"什么算 sweet zone / 什么算 overbought"。**

**实施方式**：

| 静态阈值 (v1.1) | 自适应阈值 (v1.2) |
|:---|:---|
| WT1 ∈ [20, 40] | WT1 ∈ [历史中位数, 历史80分位数] |
| ADX > 20 | ADX > 历史70分位数 + 30 天前 < 历史30分位数（拐点）|
| 5d ret > +2% | 5d ret > 历史70分位数 + 30 天前 < 历史30分位数 |
| 20d ret > +10% | 20d ret > 历史80分位数 |
| HV pct > 70 | 已自适应，但需加 transition（HV 从 < 30 升到 > 70）|
| 位置 < 30% | 位置 < 历史20分位数（per-stock）|
| 板块 -10% / +5% | 板块相对强弱 < -1σ / > +1σ（per-sector σ）|

### 13.6 Lookahead Bias 防护

**关键原则**：计算分位数时**排除当前值**——避免把今天的数据用于判定今天的状态。

```python
# 错误做法 (lookahead bias)
percentile = (series.iloc[-252:] <= cur_value).sum() / 252

# 正确做法 (排除当前值)
window = series.iloc[-(252+1):-1]  # 取 252 个历史值, 不含当前
percentile = (window <= cur_value).sum() / 252
```

**实际窗口**: 至少 60 个交易日（避免样本过小）；理想 252 个交易日（覆盖一年）。

```python
# 来自 /Users/weimingzhuang/Documents/source_code/Vibe-Trading/.../v21/alpha_engine_common.py
def calc_v21_ob_threshold(mcap_series, ticker, ob_base=53, ob_cap_adj=40):
    mcap_pctile = mcap_series.rank(pct=True).get(ticker, 0.5)
    threshold = ob_base + ob_cap_adj * mcap_pctile
    return threshold, mcap_pctile
    # 小市值股票: threshold ≈ 53 (低 OB)
    # 大市值股票: threshold ≈ 93 (高 OB)
```

**用法**：buy_ladder batch 模式下，给定整个 universe 的市值序列，对每只股票计算其自适应 OB 阈值。然后：
- 如果 WT1 > threshold → 该股票超买，buy 过滤掉
- 如果 WT1 ∈ [40, threshold] → 该股票在 sweet zone，buy 信号
