# HYP_UPDATE_RULES.md — 概率更新规则

> **创建:** 2026-08-04
> **触发:** 评论指出三剧本概率（029:50-55%/028:30-40%/027:10-15%）一周内从 40-50/45-50/15-20 重分配，标注"用户分级"——本质是把直觉写成百分数。**方案 B 实施：保留数字 + 加显式更新规则 + 季度 Brier 校准**
> **协议层:** 每次概率更新必须 (a) 可追溯（时间戳+信号） (b) 可证伪（截止日+反向条件） (c) 可校准（季度 Brier）
> **关联:** HYPOTHESES.md（描述）/ BROKER_OBSERVATION.md（券商监控）/ CHINA_FRAMEWORK.md §10.1（CDS）/ US_FRAMEWORK.md §1.3（双剧本）/ decision-journal/（登记与评分）

## 0. 总协议

| 规则 | 内容 |
|------|------|
| **更新触发** | 仅由可观察信号（数据/事件）驱动；不接受"用户偏好重分配"作为概率更新机制 |
| **每次更新** | 必须写入 `decision-journal/YYYY-MM-DD.md`，记录旧值→新值+触发信号 |
| **截止日** | 每个 HYP 配一个主截止日；届时按实际结果触发 Brier 评分 |
| **Brier 阈值** | 0.25 = 瞎猜 50/50；<0.15 = 框架在加值；>0.25 = 框架在伤害 |
| **5-Why 蒸馏** | 连续 2 季度 Brier > 0.20 → 重新审核本文件的更新规则 |
