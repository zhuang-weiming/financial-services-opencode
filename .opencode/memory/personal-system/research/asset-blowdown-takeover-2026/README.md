## 用途

量化"债务重组通过资产崩盘实现财富再分配"(blowdown-takeover) 机制的敏感性:
- **Model 1:** 崩盘→恢复路径 (forced seller → buyer 的再分配)
- **Model 2:** 长期通胀/金融抑制路径
- 验证 1946-74 历史基准 (g_nom 7.4% > i 4.2%, 实际利率 +1.7%, 债务动态模型误差 0.013pp/年)
