## 用途

基于历史数据 + 当前事实, 量化推演两种美债危机剧本:
- **A) 慢速剧本 (HYP-028):** 20 年金融抑制 + 通胀税
- **B) 快速剧本 (HYP-027):** 8-10 年危机驱动重置

并验证三个用户论点:
1. "USD 贬值但相对其他货币仍较保值"
2. "RMB 对 USD 升值, 但商品价格仍上涨"
3. "全球主要货币同步贬值 vs 商品"
