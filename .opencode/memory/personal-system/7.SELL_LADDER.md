## 一、卖出哲学 (3 条核心原则)

### 原则 1: 让利润奔跑 (Let Profits Run)
- 强动能期: 14 skill 中 5/5 强动能信号全部看多 → 持有 100%
- **不要**因为"涨多了"就卖
- **不要**预测顶部
- ✅ 让趋势自己结束, 用客观信号判定

### 原则 2: 多信号共振 (Multi-Signal Confirmation)
- 单信号 (RSI>80, WT1>60) 不可靠 → 容易卖飞
- 至少 3 个动能结束标志同时出现 → 才是真正的顶
- 14 skill 强动能信号衰减到 ≤ 2/5 → 大幅减仓

### 原则 3: 保护性止损 + 顺势止盈 (Protective + Take-Profit)
- **止损**: 跌破关键支撑 (EMA12, 上升趋势线) → 减 20%
- **止盈**: 价格触达目标位 → 分批 (不预判顶部)
- **兜底**: 化债 deadline 不可豁免

## 三、5 大动能结束标志 (多信号共振)

**真正"动能结束"是以下 5 个标志中至少 3 个同时出现**:

| 标志 | 具体触发 | 量化标准 |
|:---|:---|:---|
| **① 趋势破坏** | EMA(12) 跌破 + ADX < 20 + ichimoku 跌破云 | 3 个全触发 |
| **② 动量反转** | WT1 dead cross + RSI 持续 < 30 + 20d 动量 < -10% | 3 个全触发 |
| **③ 量能背离** | OBV 下降 + 价格新高 (bearish divergence) | 5 日内 OBV↓ + 高点↑ |
| **④ 结构破坏** | smc ChoCH + chanlun 顶分型确认 + ichimoku 跌穿云 | 3 个全触发 |
| **⑤ 波动率突变** | HV 100% → 骤降到 30% (平静 = 没人追) | 30 日内 HV -70pp |

**判定:**
- 0/5 触发: 强动能期 → 持有 100%
- 1-2/5 触发: 动能衰减期 → 准备分批
- **3-4/5 触发: 动能结束期 → 大幅减仓** ⭐
- 5/5 触发: 趋势反转 → 全面清仓

## 七·五、v2.2 升级（分级计票，BT-008 实证定案）

> **为什么改:** v2.1 阶段 3 阈值过敏感 → 2026 科技股行情踏空主升浪（阶段3后 fwd20d 4/7 标的为正, 最贵海光 +23.2%）。
> 用户假设：candlestick/chanlun/ml-strategy 是**事件信号**（明确买卖点）, 比趋势信号更值钱 → 加权验证。

### 分级计票 (score_v22)

| 级别 | 信号 | 权重 | 理由 |
|:---|:---|:---:|:---|
| **事件信号** | candlestick / chanlun / ml_strategy | **×2** | 明确买卖点, 加权后阶段3误杀减 76% |
| **趋势信号** | alpha_engine_v21 / technical_basic / ichimoku / smc / alpha_zoo / multi_factor | ×1 | 方向判定, 不预判顶 |
| **辅助观察** | harmonic / pair_trading / volatility / factor_research | 0 | 不参与计票 (factor_research 死灯 bug 教训) |

- score = 2·event_pos + 1·trend_pos − 2·event_neg, max = 12
- 阶段 1 ≥ 0.75·max (9), 阶段 3 < 0.42·max (5)

### 阶段 3 防误杀（v2.2 新增）

| 得分 | 动能结束标志 | 判定 | 动作 |
|:---:|:---:|:---|:---|
| < 5 | ≥3 共振 | 阶段 3: 动能结束期 | 🔴 大幅减仓 (减 70-100%) |
| < 5 | <3 | **阶段 2.5: 得分触底未共振** | 🟠 减 20-40% 观察, 不恐慌清仓 |

### 权重扫描实证 (BT-008, 7 标的 × 28 周)

| 模型 | 踏空代价 (s3_med_miss) | 持有质量 (s1_med_hold) |
|:---|:---:|:---:|
| v2.1 等权 5 强 | 7.03% | 3.54% |
| v2.2 事件×1 | 4.55% | 1.11% |
| **v2.2 事件×2 ⭐** | **1.71%** | 1.11% |
| v2.2 事件×3 | 2.48% | 0.68% |

**结论: 事件×2/趋势×1 为正式配置。** 通用化: 任意股票可跑（Sina 自动下载落盘）。
