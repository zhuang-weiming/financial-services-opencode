## 一、卖出哲学 (3 条核心原则)

### 原则 1: 让利润奔跑 (Let Profits Run)
- 强动能期: 14 skill 中 5/5 强动能信号全部看多 → 持有 100%
- **不要**因为"涨多了"就卖
- **不要**预测顶部
- ✅ 让趋势自己结束, 用客观信号判定

### 原则 2: 多信号共振 (Multi-Signal Confirmation)
- 单信号 (RSI>80, WT1>60) 不可靠 → 容易卖飞
- 至少 3 个动能结束标志同时出现 → 才是真正的顶
- 14 skill 强动能信号衰减到 ≤ 2/5 → 大幅减仓

### 原则 3: 保护性止损 + 顺势止盈 (Protective + Take-Profit)
- **止损**: 跌破关键支撑 (EMA12, 上升趋势线) → 减 20%
- **止盈**: 价格触达目标位 → 分批 (不预判顶部)
- **兜底**: 化债 deadline 不可豁免
### 原则 4: 三因子破裂即触发 (LAW-004 整合 · doc-v2.4.1 分层)

- **底层公理:** 好股票 = 好公司 × 好价格 × 好政策（LAW-004）
- **触发逻辑（doc-v2.4.1，2026-09-04）:** **Gate A（好公司）或 Gate C（好政策）任一破裂即触发减仓——不论技术信号多亮、价格多强势、动能多强**（公理层：标的变质/政策反转不可逆）；**Gate B（好价格消失 = 估值变贵）为咨询性**——不单独触发减仓，与动能结束信号叠加判断（"好价格"随上涨自然消失，若单独硬触发会与原则 1"不要因为涨多了就卖"直接冲突，见 CONFLICT-LAW001-LAW004）
- **核心原则:** 卖出的根本理由不是"涨多了"，而是"标的变质了"
- **与既有触发的关系:** 与信号矩阵并列（非替代），但 Gate A/C 破裂**优先级高于信号矩阵**——三因子 A/C 破裂 = 不可逆损伤，必须先处理

## 一·五、LAW-004 三因子卖出触发（doc-v2.4.1 修订 — Gate A/C 硬触发 + Gate B 咨询性）

> **状态：** USER_RULE → LAW 候选（未做 BT 验证，2026-08-30）。**doc-v2.4.1（2026-09-04, P0-2 裁定）**：Gate A（好公司）与 Gate C（好政策）破裂 = **硬触发**（优先级最高，不论技术信号多亮）；**Gate B（好价格）降为咨询性**——估值变贵不单独触发减仓（"好价格"随上涨自然消失，若硬触发将与原则 1"让利润奔跑"冲突；且经验阈值未经 BT），与动能结束标志叠加使用。

### 触发一：好公司不成立（🔴 严重，Gate A 破裂）

| 子触发 | 具体信号 | 减仓动作 | 验证期 |
|---|---|---|---|
| **财务造假曝光** | 公告 / 媒体 / 审计意见 | 立即减 50%；财报确认 → 减至 0 | 即时 |
| **管理层重大失信** | 证监会处罚 / 股东诉讼 / 实控人失联 | 立即减 50%；监管结论 → 减至 0 | 30 日内 |
| **主营业务模式破坏** | 主营收入占比从 > 70% 跌至 < 50% 且持续 2 季度 | 减 50%；下季度验证 | 季度 |
| **ROE 持续恶化** | ROE 5Y 均值从达标 → < 行业 median 的 50% 且持续 2 年 | 减 25%；年度验证 | 年度 |

**核心逻辑：** 好公司破裂 = 不可逆损伤。**与价格无关**——即使股价创新高、信号全亮，造假公司不应持有。

### 触发二：好价格不成立（⚪ 咨询性 — Gate B 破裂不单独触发，doc-v2.4.1）

| 子触发 | 具体信号 | 咨询性动作 |
|---|---|---|
| **估值进入极贵区间** | PE TTM 5Y 分位 > 90% **或** PB 5Y 分位 > 90% | 提示：与动能结束标志叠加评估（不单独减仓）|
| **P/FV 显著高估** | Morningstar P/FV > 1.5 | 提示：同上（可触发"评估卖出"级 ⭐ 参考）|
| **Graham 数跌破** | 股息率 + 增长率 < 5% | 提示：同上 |

**Graham 数 5-10% 区间：** 默认**观察区**（监控，不触发减仓）——理由：5-10% 接近门槛但未明确跌破，需结合其他估值指标判断，避免假信号。

**核心逻辑（doc-v2.4.1，2026-09-04）：** 好价格消失 = 机会成本风险，**价格波动可逆**。Gate B 降为咨询性的两个理由：(1) 估值变贵是**上涨的自然结果**——若硬触发则与原则 1"让利润奔跑/不因涨多而卖"直接冲突，也与 LAW-001 动量追入冲突（CONFLICT-LAW001-LAW004）；(2) 阈值未经 BT 验证。当前执行：估值极贵仅作为**与动能结束信号叠加的确认项**（如 5 大动能结束标志 ≥3 + P/FV>1.5 → 减仓幅度可上调一档）；待"Gate B 过滤回测"（对标 BT-013/014）后再评估是否恢复硬触发。

### 触发三：好政策不成立（🔴 严重，Gate C 破裂）

| 子触发 | 具体信号 | 减仓动作 |
|---|---|---|
| **行业从扶持转打压** | 国家战略名单移除 + 监管打压文件出台 | 减 50% |
| **HYP 台账标"风险"** | 相关 HYP 从"受益"或"中性"标"风险" | 减 50%（立即）|
| **监管周期进入打压期** | 反垄断高潮 / 集采极端 / 限价令 | 减 50% |
| **国际环境恶化** | G2 默契破裂（参考 HYP-032 证伪条件）| 减 25-50%（视破坏程度）|
| **汇率冲击** | 人民币急贬 > 5% 单月 | 减 25%（人民币资产）|

**核心逻辑：** 好政策反转 = 不可逆风险。**减仓幅度等于因子一**——政策传导有滞后，识别时已晚，必须快速反应。

### 优先级与互斥规则（doc-v2.4.1）

```
优先级（高 → 低）：
  ① 好公司破裂（Gate A，硬）> ② 好政策反转（Gate C，硬）> ③ 14 信号矩阵 > ④ 好价格消失（Gate B，咨询性，仅叠加） > ⑤ 时间锚
```

- Gate A/C 任一触发 → 必须执行（即使技术信号全亮）
- **Gate B（好价格）为咨询性**——不单独触发减仓；仅在动能结束信号共振时作为减仓幅度上调的叠加确认（2026-09-04 P0-2 裁定，见 6.CONFLICTS.md CONFLICT-LAW001-LAW004）
- 多因子同时触发 → 取**最大**减仓幅度（不累加，避免过度反应）
- 三因子 A/C 未触发但信号矩阵触发 → 按既有流程执行（保持兼容）

### 关键风险（来自 1.LAWS.md LAW-004 5-Why）

- "好政策"判断存在主观性——以 HYP 台账 + C1/C4 代理指标为锚，避免后视偏差
- Gate B 与 LAW-001 动量延续存在"空集问题"——**已登记 CONFLICT-LAW001-LAW004（2026-09-04 OPEN）**；处置 = Gate B 降咨询性（买入端 8.BUY_LADDER v3.5 / 卖出端本文件 doc-v2.4.1），待"Gate B 过滤 vs 不过滤"回测后再评估是否恢复硬约束
- "好公司破裂"中渐进型恶化（ROE 下滑、护城河侵蚀）需**季度复审 + 月度扫描**，不能仅靠公告触发
