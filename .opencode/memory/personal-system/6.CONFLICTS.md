### CONFLICT-LAW001-LAW004: LAW-001 动量追入 vs LAW-004 Gate B 好价格 — "空集问题"

- **类型:** LOGICAL_CONTRADICTION｜**登记:** 2026-09-04（LAW-004 立条当天首提）
- **甲方:** LAW-001（低 WT1 不反转 → Buy-Ladder 必须"动量已起再追入"）
- **乙方:** LAW-004 Gate B（PE/PB 5Y 分位 <30% ∧ P/FV <0.85）
- **矛盾本质:** A 股动量股的价格已显著上涨 → 估值分位大概率 >30% → Gate B 会**系统性过滤掉 LAW-001 定义的击球区** → 三因子 gate 在理论层面"永远无法入场"
- **5-Why 根因:** 两条硬规则**互相锁死**——"只追动量" ∧ "只在便宜时买"在 A 股几乎互斥，规则叠加时未做**可满足性（satisfiability）检查**
- **框架偏差:** 单条规则各自成立，连成链条后可能锁死整个系统（Buy 端永不买 / Sell 端永远卖飞）
- **处置:** Gate B 降为**咨询性**；Gate A/C 保持硬约束；未做 BT 验证
- **状态:** **OPEN** —— ⚠️ **2026-09-15 新证据：空集问题未被解决，只是迁移到 → CONFLICT-LOGIC-013**

### CONFLICT-LOGIC-002: "券商 = CSI 300 Beta"是因果倒置还是同义反复？

- **类型:** LOGICAL_CONTRADICTION｜**登记:** 2026-07-22
- **甲方:** LAW-003 —— 券商驱动力为"CSI 300 Beta（r>0.93）"
- **乙方:** 框架结论"券商有 2-3 倍空间"，但**框架从未独立论证"CSI 300 会涨"**
- **矛盾本质:** 若券商 = CSI 300 × 1.5x Beta，则"2-3 倍空间"等价于"CSI 300 涨 60%+"。框架没有回答这个关键前提
- **5-Why 根因:** 框架**擅长回答"为什么不会大跌"**（国家队托底 + 存款搬家），**不擅长回答"为什么会大涨"**——缺乏一个清晰、排他性的牛市驱动逻辑
- **处置:** 保留 Beta>0.93；"2-3 倍空间"改为"弹性为 CSI 300 的 1.5-2x，上行依赖 CSI 300 方向"
- **状态:** **OPEN**（2026-07-29 单日 +1.26pp 超额支持 Beta>1，需 5+ 交易日连续验证）

- **状态:** **OPEN**（v2 pilot 中；阈值校准 + 历史回测待完成）

### CONFLICT-LOGIC-012: `3.2` 预判 5「共识前建仓」vs 预判 7「不抄底、2026 等待年」

- **类型:** LOGICAL_CONTRADICTION — **框架内部矛盾**（同一份 `3.2` 文件内）｜**登记:** 2026-09-15
- **甲方（支持买入）— 预判 5 反共识策略:**
  > 「军工信息化｜共识触发 = 十五五 + 国防预算 +10%｜**共识前**加主机厂+上游 → 共识时兑现」
  十五五定调在预判 2 中列于 **2027-Q4** → **2026-09 建仓 = 标准的"共识前"**，与预判 5 完全一致
- **乙方（反对买入）— 预判 7 原则 2/7 + 一句话最终判断:**
  > 「LAW-001 纪律：**只追动量确认（高 WT1），不抄底（低 WT1 median −1.82%）**」
  > 「**2026 = 等待准备年**：大部分已 price-in，持有 30% 实物主权资产 + 等回调」
  > 「操作：**不抄底、只追动量确认**」
- **触发案例:** 2026-09-15 卖出方正证券 → 买入 563530 卫星ETF（当前 **WT1 = −32.34**，处 LAW-001 低 WT1 负 median 区）
- **矛盾本质:** 同一框架**同时授权"共识前建仓"和"绝对不抄底"**。用户的买法完全符合预判 5，同时完全违反预判 7 原则 2/7
- **5-Why 根因:** **"反共识建仓"与"动量确认建仓"是两条互斥的入场通道，框架从未裁决哪条优先**——前者靠叙事判断，后者靠价格证据，入场时点天然冲突
- **框架偏差:** 框架擅长**生成主题与剧本**（预判 4/5），但**未把"主题"转化为可执行的入场纪律** → 执行层只能用 LAW-001 兜底，而 LAW-001 与主题布局逻辑互斥
- **处置（三选一，待用户裁决）:**

| 方案 | 内容 |
|---|---|
| **A. 承认双通道** | "反共识建仓"为独立通道，与 LAW-001 并列 → **必须单独写风控**（小仓位 + 政策里程碑验证 + 时间止损） |
| **B. LAW-001 优先** | 接受 LAW-001 优先 → 等 WT1 转正 / 站上 1.114 再进 |
| **C. 二者并用** | 主题仓位拆两半：一半"共识前小仓试探"，一半等"动量确认后加" |

- **⚠️ 当前状态（问题所在）:** 用预判 5 的理由买入，却不设预判 7 要求的动量确认 = **两条纪律都不遵守**
- **状态:** **OPEN**（待裁决 A/B/C；阻塞 563530 后续加减仓规则）

### CONFLICT-LOGIC-013: LAW-004 Gate B 咨询性 vs BUY_LADDER 否决⑤ 硬否决

- **类型:** LOGICAL_CONTRADICTION — 规则的**迁移**而非解决｜**登记:** 2026-09-15
- **甲方:** LAW-004 —— Gate B（好价格）＝ **咨询性**。降级理由原文：「A 股动量股天然估值高，Gate B 拒绝大部分动量赢家，与 LAW-001 方向相反——**这个交集可能接近空集**」
- **乙方:** LAW-004 同条 —— 「极端高估防线由 BUY_LADDER 5 大否决⑤（**PE/PB 5Y >70% 分位一票否决**）承接，**无需 Gate B 把关**」
- **矛盾本质:** Gate B 降级的**理由是"硬估值门会造成空集问题"**；但同条把估值防线**委托给一个更严的硬门**（原来 <30% 单侧，现在 >70% 一票否决）。**空集问题并未解决，只是从 Gate B 迁移到否决⑤**
- **触发案例:** 563530 卫星ETF —— Gate B 不通过（指数 PE 77.2 分位）**且** 否决⑤ 触发 → 判定禁入区。**一个 LAW-001 意义上的主题动量候选，仍被硬估值门拒之门外**
- **5-Why 根因:** **把"降低某个门的强度"误当成"解决门与门的冲突"**。真正的冲突不是"Gate B 太严"，而是**"估值门与动量逻辑在原理上互斥"**——无论放在 Gate B 还是否决⑤，只要它是硬的，空集问题就存在
- **框架偏差:** **用"重新分配规则的位置"代替"裁决规则之间的优先级"** —— 架构层面的冲突被处理成了配置层面的调整
- **处置（待裁决）:**
  1. 明确裁决估值门 vs 动量逻辑**哪个优先**（不能两者都要）
  2. 若保留硬否决⑤ → 须承认"高估值主题动量标的系统性不可买"，并接受由此放弃的机会（2023 AI / 2025 机器人行情）
  3. 若允许动量优先 → 否决⑤ 改为**条件否决**（如仅在"无政策催化 + 无动量确认"时生效）
- **状态:** **OPEN**（待裁决）

### CONFLICT-USER-AI-TERMINAL: 用户"AI 已到终点"vs HYP-002（6-8 年周期）

- **类型:** USER_FRAMEWORK_MISMATCH｜**登记:** 2026-09-15
- **甲方（用户原话）:** 「美国 GPU/韩国 Memory 是否还是当下热点，**已经成为终点的讨论，没有了 10 倍的未来**」；「中国只落后美国 AI 2 个月的情况下花费少了几十/几百倍，**美国的 AI 必然失败**」
- **乙方（框架）:** HYP-002（分层错峰，全周期 6-8 年）；HYP-006（Capex/Revenue 触发的是**减仓纪律**，不等于 AI 落幕）；4.2（5 信号 4/5 已触发 = 防泡沫，不是已死亡）

| 用户主张 | 判定 | 依据 |
|---|---|---|
| 「GPU/韩 Memory **已不是热点**」 | ❌ **事实错误** | 2026 YTD：**美光 +223.8% / SK 海力士 +149.3% / 三星 +93.4% / AMD +130.4%** —— AI 硬件是**今年全球最强资产** |
| 「资金会轮出 AI → 轮入太空」 | ❌ **无证据** | 563530 与海力士/三星日相关 **+0.39 / +0.35（全正）** —— 同向高 β，非跷跷板 |
| 「**AI 不是买入的好时机**」 | ✅ **成立** | 按用户自己框架：HYP-006 已触发 + 预判 1 的 2027-Q3 泡沫首破 → **+223.8% 的资产配"已触发清仓纪律" = 差的入场质量** |
| 「资本效率不对称（中国以极小成本接近）」 | ✅ **方向成立，机制真实** | DeepSeek 时刻证明"前沿竞争力 ≈ 资本开支规模"不成立；NVDA 单日 ≈$6,000 亿蒸发 = 该 regime break 的价格表达 |
| 「**美国的 AI 必然失败**」 | ⚠️ **过度外推** | 资本效率 ≠ 胜负。"花费少几十倍"既可能是效率，也可能是**更小上限** |

- **5-Why 根因:** 「资本效率高的挑战者 → 摧毁高成本在位者」这个机制是真的，但**把"摧毁在位者"等同于"挑战者自己的股权会涨"是跳跃**。低成本技术扩散时 surplus 通常流向**使用者**而非**生产者** —— 这恰恰是**通缩型**论点，不是通胀型交易
- **框架偏差:** 擅长识别**产业机制**（资本效率不对称、频轨资源排他性），但在**从机制推导到具体标的的股权含义**时缺少"价值链 surplus 归属"这一层
- **⚠️ 待补的框架缺口 2 条:**
  1. **ITU 频轨资源是排他性物理资源** —— 与 AI 不同，轨道/频谱不可复制、先到先得 → **"必须按时花完"机制是真的**（本轮曾标"不可核实"而处理过轻）
  2. **价值链 surplus 归属分析层** —— "中国低成本发射"对卫星产业链的股权含义可能是**通缩**（中间环节定价权被压缩），与其"通胀型交易"推论方向相反
- **状态:** **部分 RESOLVED**（"AI 已死"证伪；"AI 不是好买点"确认；"资本效率机制"确认真实；**"所以买卫星"与"美国 AI 必然失败"仍为未验证外推**）
