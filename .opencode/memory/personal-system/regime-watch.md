## 一、状态概率（下一步，动态调整）

| 状态 | 概率 | 触发"绿灯" | 触发"红灯" |
|------|------|-----------|----------|
| **A 老剧本（1966-82 滞胀）** | **22.5%**（20-25%）| NVDA 业绩崩 + WTI 破 $100 + FFR >5.5% | NVDA 业绩超预期 + CPI 持续 <3% |
| **B AI 化解** | **26.5%**（25-28%）| NVDA 业绩 >30% + AI 生产力数据 + Fed 鸽派 | NVDA Q/Q <10% 持续 2 季 + Fed 暴力加息 |
| **C 滞胀失控**（破裂 + 供给冲击，含原 D-B 跳过渡）| **37%**（35-40%）| AI 破裂 + 霍尔木兹封锁 + WTI $150+ + CPI 突破 7% | WTI 跌至 $60 + Fed 暴力紧缩 |
| **D 破裂（通缩窗口）**（仅无供给冲击路径）| **15%**（13-16%）| AI 破裂 + 中国 CPI <0% + 新兴市场危机 + **WTI ≤ $100**（无供给冲击）| 中国 CPI >1.5% + Fed 紧缩 |

**破裂路径合计**：D 15% + C 37% = **52%**；不破裂路径 B 26.5% + A 22.5% = **49%**。

**收敛点（核心叙事，2026-08-19 框架升级）**：四状态不是互斥终局，是"下一步状态"——每个状态之后还有转移（D→通胀化债 ~75% / C→A 稳态 ~55% 或硬着陆复苏 ~35% / B→渐进通胀化债 ~70%）。**$39.99T 债务（日均 +$13B）要求名义增长，所有路径最终收敛于"通胀回归 + 货币化化债"（≥90%）**。差异只在路径形态与时序：D 最快（6-12 月后）、C 直接（立即 5-9%）、B 最慢（5-10 年渐进）、A 进行中。

**D 的关键澄清（2026-08-19 用户反证）**：D 的"通缩"是**过渡窗口**（6-12 月）不是方案——$40T 国债（Fisher 债务-通缩螺旋）保证通缩不可持续，通缩窗口后必然货币化 → 通胀回归（衔接 A）。D-B 跳过渡（破裂 + WTI>$100）已并入 C，C 成为最高单一状态。

**D 剧本边界**：D 只覆盖"破裂且无供给冲击"（WTI ≤ $100）路径；WTI >$100 或地缘冲击 → C。破裂路径合计（D 15% + C 37%）= 52%。

**A 概率上调说明（2026-08-19 用户反证）**：结构性条件匹配度 80-85%——美元脱钩 ✅ + 财政主导（30Y 实际 3.06%）✅ + 供给冲击 ⚠️（WTI $82.55）；缺"最后一根稻草"（地缘供给冲击）。

**下次评估日期**: 2026-08-27（NVDA Q2 FY27 财报发布后）+ 9 月 FOMC

## 三、剧本切换规则（快速响应）

### 3.1 立即响应（24-48 小时内）

| 触发事件 | 操作 |
|---------|------|
| **30Y 拍卖 bid-cover < 2.3x** | **无条件清空长债（5% → 0%），保留短债/黄金**（不管剧本）|
| 霍尔木兹海峡封锁 | 清空股票 + 黄金 40% + 短债 30% + 能源 15% |
| NVDA 业绩 -50% 大幅低于预期 | Mag 7 减至 0% + 黄金 30% + 短债 35% |
| Fitch/Moody 降级美国主权评级 | 清空长债 + 黄金 30% + 短债 40% |
| SPY 单日跌幅 >5% | 现金升至 40% |
| WTI 单日涨幅 >15% | 加能源 + 黄金，减股票 |
| **30Y TIPS 实际 > 3.5% 持续** | 财政溢价确认 → 长债清空 + 黄金+短债 |

### 3.2 周度响应（1-2 周内）

| 触发事件 | 操作 |
|---------|------|
| NVDA Q4 业绩 <20% | 减 Mag 7 至 5% + 加黄金至 30% + 现金至 30% |
| NVDA Q4 业绩 >30% | 加 Mag 7 至 15% + 减黄金至 20% |
| WTI 突破 $100 **且 AI 破裂信号** | **C 剧本触发**：加能源股至 15% + 黄金 30% + **减长债至 0%** + 切周/日级再平衡 |
| WTI 跌至 $60 | 减能源股至 3% + 加长债（短久期）至 10% |
| CPI 持续 2+ 月 >5% | 减 Mag 7 至 5% + 加黄金至 35% + 加能源至 15% |
| CPI 持续 2+ 月 <2% | 加 Mag 7 至 15% + 减黄金至 15% + 加长债（短久期）至 10% |

### 3.3 月度响应

- FFR 突破 5% → 减股票至 30% + 加短债至 35%
- SPY 跌至 $550 → 全组合转入防御（现金 40% + 黄金 30% + 短债 15% + 股票 15%）
- SPY 突破 $900 → 增 Mag 7 至 15% + 减黄金至 20%
- 黄金突破 $5,500 → 部分获利（减黄金至 20%）+ 加短债至 30%
