# BUY_LADDER 病灶定位 — BT-013 数据报告

> 对标 sell 侧 BT-011/012 双分数定案路径, 用两年真实信号缓存回答: buy-ladder 需要什么整理 / 什么算法累计分数 / 回测如何.
> 零新下载: 复用 BT-011 信号缓存 + 200 池本地价格. 完整留痕: `backtests/BT-013/`.

## 一句话结论

**Buy-ladder 不是"太保守", 是功能性锁死——阶段 1 在两年 8.9 万次观测里从未触发; 且它的计票权重与实证完全倒挂(最强反指信号拿最高权重, 唯一能赚钱的信号拿最低权重)。**

## ① Buy-ladder 需要什么样的整理

**不是加算法, 是先修三个病根:**

| 病根 | 数据证据 (BT-013) | 整理动作 |
|:--|:--|:--|
| **A. 阶段阈值锁死** | 声明阈 `0.65/0.42×20 = 13.0/8.4`, 而 score 实际 P99=4~5、max=6~7 → **阶段1 (击球区) 两年 0 次触发, 阶段2 也 0 次** | 改用**绝对阈值** (基于可达分布), 废除 0.65/0.42×max 比例式 |
| **B. 信号死灯** | `smc` 0%、`multi_factor`/`sector_relative`/`factor_research`/`pair_trading` 缓存置零、`turnover_anomaly` 0.086%、`ichimoku` 0.53% | 生产路径传 peer 复核; 真为 0 则移出计票, 降为否决/预警 |
| **C. 权重倒挂** | 事件信号×2 = chanlun **−1.61%** / turnover **−4.47%**(负 α); 趋势信号×1 = alpha_zoo **+0.64%** / technical_basic **+0.31%**(唯一正 α) | 权重按事件 α 重排: 正 α 晋升, 负 α 移入否决/预警 |

> **最反直觉的发现:** `chanlun`(三买) 是 buy-ladder 事件信号里权重最高的, 却是 **全市场两年最强反指** (α20=−1.61%, t=−12, p<0.0001)——触发后跑输同池 1.6%/20 日。这跟 buy 哲学自洽: buy 靠"动量延续、不预测底部"(LAW-001), 而三买是左侧反转抄底, 两者本就矛盾, 回测只是把它证明了出来。

## ② 需要什么算法累计分数 (数据答案)

事件研究给出**买入信号有效性排序** (信号>0 触发后 20 日的截面超额 α):

| 信号 | α20 (全期) | 显著性 | 2025 牛 | 2026 弱 | 角色 |
|:--|:--:|:--:|:--:|:--:|:--|
| **alpha_zoo** | **+0.64%** | p<0.0001 | +0.77% ✓ | +1.23% ✓ | **两年唯一稳定买入信号** |
| **technical_basic** | +0.31% | p=0.025 | +0.12% ✗ | **+1.30%** ✓ | **弱市专用** (α60 高达 +5.18%) |
| candlestick | +0.23% | 边际 | −0.03% | +0.79% ✓ | 弱市辅助 |
| ad_line | +0.29% | 边际 | +0.11% | +0.81% ✓ | 弱市辅助 |
| chanlun | **−1.61%** | p<0.0001 | −1.77% ✗ | −1.61% ✗ | **两年强反指 → 否决/预警** |
| turnover_anomaly | −4.47% | n=65 | — | — | 反指且稀有 → 移出加分 |

**对称 sell 侧双分数的 buy 版本 (基于 α 数据, 非拍脑袋):**
```
弱市买入分  score_w = alpha_zoo + technical_basic + candlestick + ad_line   ← 2026 四年正 α
牛市买入分  score_b = alpha_zoo ×2 + technical_basic                          ← 2025 仅 alpha_zoo 真有效
```
注意与 sell 侧**相反**: sell 靠"事件"减亏, buy 靠"趋势/动量"启动——买侧正 α 全在趋势类。

## 诚实标注 (Adversarial)

- 死灯是 **BT-011 缓存口径** (无 peer 显式置零, `bt011_engine.py:91`), 不代表 buy_ladder 生产传 peer 一定为 0 — 未验证, 结论可能收窄。
- 样本仅 2 年 (2025 牛 + 2026 弱), **无深熊**; 截面基准未风险调整; 20/60 日重叠样本使 t 检验 p 值低估。
- 结论用于**排序与方向**, 不用于精确显著性; chanlun 反指需按"三买 vs 其他"细分后再定性。
