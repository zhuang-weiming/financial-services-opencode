## 1. 登记规则

每条概率性预测必须填写以下字段：

| 字段 | 说明 | 必填 |
|------|------|:---:|
| 日期 | YYYY-MM-DD | ✓ |
| HYP ID | `HYP-XXX` 或独立预测 ID | ✓ |
| 预测内容 | 1-2 句陈述 | ✓ |
| 当前概率 | 0-100%（采用区间中位） | ✓ |
| 置信度 | HIGH / MODERATE / LOW | ✓ |
| 关键证据 | 3-5 条 bullet | ✓ |
| 截止日期 | YYYY-MM-DD | ✓ |
| 反向条件 | 触发后概率归 < 阈值 | ✓ |
| 登记来源 | 对话 / 用户输入 / 推演 / 数据触发 | ✓ |

**文件命名：** `decision-journal/YYYY-MM-DD.md`（同日多预测登记到同一文件）

## 2. Brier 评分公式

```
Brier = (forecast_prob - actual_outcome)^2
```
- `actual_outcome` ∈ {0, 1}（事件发生/未发生）
- **0.00** = 完美预测
- **0.25** = "瞎猜 50/50"基线
- **< 0.15** = 框架在加值
- **> 0.25** = 框架在伤害（不如 50/50）

**Brier 分解（可选）：**
- 分项 Brier：每条预测单独算
- 平均 Brier：季度均值
- 分 HYP Brier：按 HYP ID 分组

## 3. 季度评分流程

每季度末（3/31、6/30、9/30、12/31）后 7 日内：

1. **拉取**该季度所有登记的预测（grep `decision-journal/YYYY-MM-DD.md`）
2. **标记**每条的实际结果（截止日期 ≤ 季度末的）
3. **计算** Brier = mean((p - outcome)^2)
4. **写入** `decision-journal/brier-quarterly/YYYY-QN.md`
5. **触发** 任何 Brier > 0.25 → 写入 `CONFLICTS.md`（类型 `METHOD-CALIBRATION`）
6. **5-Why 蒸馏** 连续 2 季度 Brier > 0.20 的 HYP → 重新审核 `HYP_UPDATE_RULES.md`

## 4. 概率取值约定

| 区间表达 | 登记值 | 备注 |
|----------|--------|------|
| 50-55% | 52.5% | 区间中位 |
| 10-15% | 12.5% | 区间中位 |
| MODERATE-HIGH | 不转概率，记置信度 | 用于不可量化预测 |

**不采用区间端点的原因：** 区间是认知不确定性，端点会引入伪精确。中位 + 显式区间更诚实。
