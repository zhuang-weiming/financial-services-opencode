# BT-019 — V5 观察区(≥3) 20d 短持策略验证 (is V5 a real edge or a 2026 artifact?)

- **日期:** 2026-09-01 (首跑)
- **执行者:** backtest-builder (BT-019/bt019_v5_short_hold.py)
- **假设 (来自 BT-017 的 V5 发现):** 均匀 50% 仓位 × 观察区 (score≥3) 事件 × 20d 持有 组合 Sharpe 0.839 为 BT-017 全场最高, 但 60d 崩塌 (0.405)。需要专门验证: 20d 边际是真实稳健的信号优势, 还是短持窗口的样本伪影 (2026 弱市 beta / 事件集选择 / 日历缺陷)?
- **数据 (零新下载 — 复用 BT-011):**
  - 信号: `BT-011/results/signal_cache_v2.parquet` (16 信号, 200 池, 2024-10-08~2026-08-13)
  - 价格: `data/market/daily/<code>*.csv` (200/200 覆盖)
  - 池: `BT-011/pool_200.json`
  - 基准: `data/market/daily/510300.csv` (CSI300 ETF)
- **样本期:** 2024-10-08 ~ 2026-08-13 (2025 牛 + 2026 弱, 与 BT-011~017 同窗; 活动窗口 NAV 锚定 459 交易日)

## 方法 (相对 BT-017 的三处关键修正)

| # | BT-017 做法 | BT-019 修正 | 影响 |
|:-:|:--|:--|:--|
| 1 | 事件聚类 gap 按**事件索引** (60 个过滤后事件 ≈ 240+ 交易日) | 按**交易日** (每股每 60 交易日窗口首个 score≥3, 文档意图) | 事件数 348→1051 (ge3), 299→838 (ge4) |
| 2 | 组合 NAV 从 2022-11 联合日历起 (样本前 ~450 平盘日) | 活动窗口起 (首全局交易日 ≥ 2024-10-08) | 平盘日稀释效应实测极小 (0.4760 vs 0.4761), 非主因 |
| 3 | `dropna(alpha20,alpha60)` 剔除无完整前向收益的事件 (= 剔除 2026-05-15 之后全部事件, 含 7 月暴跌段) | 保留全部事件, 持有窗口在数据末端截断 (真实口径) | **BT-017 0.839 的主要膨胀源** (见 §BT-017 复现) |

- **计分 (BT-016 W_B):** score = 2·I(technical_basic>0) + 2·I(alpha_zoo>0) + 1·I(candlestick>0) + 1·I(ad_line>0), max 6; ≥4 击球区 / ≥3 观察区+击球区。仓位统一 0.50。
- **组合模拟:** 事件日收盘进场 (entry_lag=0), 或次一交易日收盘进场 (entry_lag=1, T+1 保守口径); 固定持有 5/10/20/30/40/60 交易日; 并发仓位 pro-rata 缩至 ≤100% NAV (无杠杆); 成本按 BT-009 惯例 0.275%/边 (0.55% 往返) 施加于进/出场名义额; 指标 = 年化 Sharpe (活动窗口) / max DD / 总收益 / 平均持仓数 / 年化换手 / 月度收益。
- **对照组 (关键):** ① ≥4 击球区同网格 (BT-016 口径); ② 200 池等权买入持有 (pool BH); ③ 510300 买入持有; ④ **随机进场控制** (每代码按实际事件数均匀随机抽取进场日, 相同持有, 300 次重复) — 检验 20d 边际是信号驱动还是市场 beta。

### B. BT-017 0.839 复现审计 (关键方法论发现)
| 口径 | ge3-20d Sharpe | 说明 |
|:--|:-:|:--|
| BT-017 公布 | **0.839** | 348 事件 (剔除了 2026-05-15 后事件) |
| 同事件集 + 全日历 NAV (复算) | **0.476** | 371 事件全保留 (今日复跑 BT-017 脚本仍输出 0.839 — 因为其脚本内部 dropna 剔除了尾部事件) |
| td60 全事件 + 活动窗口 | **1.145** | 1051 事件 |

**根因:** BT-017 的 `EV = E.dropna(subset=['alpha20','alpha60'])` 剔除了所有无完整 60d 前向窗的事件 — 即 2026-05-15 之后的全部事件, **恰好包含 2026-07 暴跌段**。0.839 是"剔除尾部最差事件"后的幸存者口径。此外事件索引聚类 (348 事件) 事件面太薄, Sharpe 对 ±6% 事件集扰动敏感 (±0.36)。**BT-017 的 V5-20d 0.839 不可作为证据引用。**

### C. 随机进场控制 (300 次, 同事件数, 同持有) — 决定性检验
| hold | 随机 Sharpe 均值 | 随机 p5 / 中位 / p95 | V5 Sharpe | **V5 百分位** | 随机总收益均值 | V5 总收益 |
|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| 5d | 1.33 | 0.73 / 1.33 / 1.98 | −0.14 | **0.0%** | +88% | −14% |
| 20d | 1.45 | 1.09 / 1.45 / 1.81 | 1.145 | **9.0%** | +100% | +68% |

| 30d | 1.46 | 1.20 / 1.47 / 1.77 | 1.247 | **10.0%** | +101% | +79% |
| 20d (ge4 事件数) | 1.51 | 1.15 / 1.48 / 1.92 | 1.468 | **46.0%** | +110% | +104% |

**结论: 该窗口内"任意 20-30d 固定持有、等权、50% 仓位、pro-rata 100%"的池子滚动书, 随机进场日的中位 Sharpe 就有 ~1.45 (毛) / ~1.17 (净)。V5 信号进场时机落在随机分布的 7~10 百分位 — 信号时机不但没有贡献, 还略差于随机。** 0.839/1.145 的 Sharpe 是池子 beta (小盘/动量池 2025 大涨) + 短窗, 不是信号 alpha。ge4 击球区 (46 百分位) 与随机无显著差异。

### H. 事件密度 / 集中度
- 570 事件/年 (td60); 2024H2=171, 2025=590, 2026(至 8/13)=290。
- **200/200 代码均有事件**, 单代码最多 7 个, top-10 代码仅占 6.7% — **不集中在少数股票**。

### J. 成本敏感性 / 盈亏平衡
- V5-20d: 净 (0.275%/边) 毛 1.15→0.88; 换手 27.1/yr; **盈亏平衡成本 1.02~1.16%/边** (30d: 1.69~1.91%/边)。
- 10d: 盈亏平衡 0.27~0.36%/边 — 短持成本敏感。
- **"是否扛得住成本"的回答: 20d/30d 扛得住 (breakeven >> 0.275%), 但这无意义 — 因为毛口径就已输给随机进场与买入持有。**

## 结论 (Verdict)

1. **V5 (≥3, 20d 短持) 不是真实稳健的 edge, 是样本伪影。** 决定性证据: 随机进场控制 (同事件数、同持有、同仓位) 中位 Sharpe ~1.45 (毛) / ~1.17 (净), V5 信号时机落在 **7~10 百分位** (比随机还差); 2025 牛年净 Sharpe 2.53 vs 2026 弱年 0.20; 事件级 α 全不显著 (20d p=0.16) 且中位数为负; 池子买入持有 +77% 跑赢 V5 毛 +68% / 净 +46%。**BT-017 的 0.839 本身是"剔除 2026-05-15 后事件 (含 7 月暴跌)"的幸存者口径伪影 (同口径复算仅 0.476)。**
2. **数据下最佳持有期: 30d** (ge3 净 1.07 / ge4 净 1.38, 两成本口径一致最优); 20d 次之; 60d 修正聚类后不崩塌 (1.03/1.20); 5d 因成本与短时反转最差。但 10-60d 全部落在随机等价带内 — 持有期差异是 beta 时点噪声, 不是信号属性。
3. **扛得住成本但无意义:** 20d/30d 盈亏平衡成本 1.0~1.9%/边 >> 0.275%/边; 但毛口径已跑输随机与 BH, 成本讨论不改变结论。
4. **不靠少数事件 (股票维度):** 200/200 代码有事件, top-10 仅 6.7%; 但**时间维度高度集中** (2025-H2 + 2026-H1 两个窗口), 且 BT-017 的 0.839 恰好来自剔除尾部事件。
5. **建议: 废弃 V5 作为独立策略形态。** 不落地 buy-ladder "short-swing mode"。观察区/击球区积分系统的价值保留在 BT-016/017 的**持仓期动量延续** (重复事件 α) — 那是"已持有如何管理"的属性, 不是"何时进场"的择时能力。若要在 200 池内保持参与, ge4 30d 净 +91% ≈ 池 BH 水平 — 等价于"有纪律地满仓持池", 不是 alpha。

## 对 memory 的影响
- BT-017 "V5 20d Sharpe 0.839 全场最高 → 扩大事件面" 结论 **需下修**: 该数字含幸存者剔除伪影; 修正口径下 V5 优于 V1 的部分主要是池 beta, 随机对照组证明信号时机无正贡献。
- BT-016/017 "首入场 α≈0, 重复事件 α>0" 的口径澄清仍成立, 且是本回测最好的解释框架: 买入点择时无 edge, 持仓期动量延续是唯一的正 α 来源 (但同样未通过随机对照的绝对检验 — 它衡量的是池内相对动量, 池外 vs 随机仍是 beta)。
- LAW-001 (动量延续) 不受影响 — 本回测不支持"反转/抄底"类替代, 只否定"用积分信号做短持择时"。

## 限制 (Adversarial Review)

- **最可能出错处:** ① 随机进场控制的对照口径 = "同样 50% 仓位 + pro-rata 100% + 固定持有" — 若真实用户用不同仓位/退出规则, 对照结论可能偏移 (但主结论"毛口径跑输 BH + 随机"对该自由度稳健); ② 2026 只到 8/13, 60d 持有的 2026 事件在数据末端截断 (与 V5 同等待遇); ③ 未建涨停/停牌可成交性 (7.6% 涨停进场日), 未建滑点非线性; ④ 2 年样本无深熊 — "20d 短持在深熊是否更差"未测; ⑤ 事件级 α 用同池等权截面基准, 未风险调整。
- **最容易被误读:** "修正后 V5-20d Sharpe 1.15 > BT-017 的 0.839 = V5 更好了" → **错误**, 两个数字都输给随机进场 (9 百分位); "30d 最佳 → 用 30d" → 30d 只是 beta 噪声里的局部最优, 与随机中位 1.46 无差; "扛得住 1%/边成本 = 策略好" → 毛口径已输, 成本承受力不构成证据。
- **Regime 变化检测:** 若 2025 式小盘动量牛重启, "20d 滚动持池"类 beta 会再现高 Sharpe (无论信号); 若转 2026-H2 式阴跌, 该形态净收益 ≈ 0。任何"短持轮动"结论必须附带"这是池 beta"的标签。
- **推荐重跑频率:** 每季度; 补深熊 (2018/2022) 样本后必重跑 — 但随机对照应作为标配, 不跑随机对照的 Sharpe 数字一律降权引用。
- **分拆验证建议:** ① 深熊样本下同网格 (2018/2022, 需下载历史信号); ② 排除涨停日进场的净效果; ③ ge4-30d 作为"持池纪律"与 buy-ladder 生产逻辑的衔接验证; ④ 重复事件 α (持仓期动量) 与随机对照的同口径比较 — 确认"持仓期 α"是否也只是池 beta。
