# BT-011: SELL_LADDER v2.5 分级计票规则适用性回测 — 2026 弱市 × 200 只全池

## 假设（用户问题）
"回归 Vibe-Trading 原版后，这样子的积分规则（EVENT×2 + TREND×1 分级计票、max=14、阈值 0.65/0.42·max）在 2026 年行情中还适用吗？"——用 200 只 A 股 × 2026 日K 回测，定案积分方式与算法。

## 方法
- **标的:** 200 只（持仓 15 + 2026 年初涨幅 top50 科技主线 + 7 月大跌 75 + 随机补齐 60），pool_200.json
- **数据:** data/market/daily/ 日K（warmup 2024-10-01 起裁剪），回放区间 2026-01-05 → 08-10
- **信号:** 16 skill 逐日序列（ml_strategy 每 20 日重训、chanlun 每 5 日降频），**5 大动能结束标志精确实现**（check_momentum_end_signals：trend_break / momentum_reversal / volume_divergence / structure_break / volatility_drop，含 OBV 量价背离），缓存 signal_cache_v2.parquet
- **计票变体 × 5:** V0_v25_current(2,1) / V1_equal(1,1) / V2_penalize_trend_neg(2,1,-) / V3_equal_penalize_neg(1,1,-) / V4_event_only(2,0)
- **阈值组 × 4:** v25_orig(9.1/5.88) / thr_hi(5.0/3.0) / thr_mid(3.0/2.0) / thr_lo(2.0/1.0)
- **阶段→仓位:** {1:1.0, 2:0.7, 2.5:0.8, 3:0.2}，T+1 生效；对照买入持有（BH）
- **流程:** bt011_engine.py（信号+回测主引擎）→ thr_scan.py（阈值扫描，复用缓存）→ 配对 t 显著性检验

**根因:** 2026 弱市信号分布下 score 均值 0.86（max 7），90% 时间 score < 5.88（阶段 2 阈值），阶段 1 阈值 9.1 不可达 → 98% 时间卡阶段 2.5（恒久 0.8 仓位）→ 积分权重无影响。V4 vs V0 配对差仅 -0.46pp（p=0.0008，**V4 显著更差**但差异微小）。

|:---|:---:|:---:|:---:|:---:|:---:|

**V4 vs V0 配对检验（全部阈值组）: p ≥ 0.20，无一处显著。** BH 年化 Sharpe 均值 -0.13。

**关键事实：**
1. **2026 所有配置 Sharpe 均为负**（弱市年日收益均值<0），策略价值是"亏得更少"（excess 正、DD 改善 8pp），不是收益质量——excess 与 Sharpe 两个口径必须分开表述。
2. **修正声明：** "V4 最优"仅成立在 **excess 口径 + thr_mid 阈值**（+6.27% vs +5.35%, p=0.022）；**Sharpe 口径下 V4 与 V0 无显著差异**，不得再表述为"V4 最好"。
3. 文件：`results/sharpe_scan.csv`（16 组合 × Sharpe 均值/中位/胜率 + 逐股序列）。

## 结论
1. **计票结构合理，阈值不适用。** v2.5 的 0.65/0.42·max 固定比例阈值在 2026 弱市信号分布下使阶段 1/2 不可达（98% 卡阶段 2.5），积分方式无法从回测中定案——**"恒久减仓 20%"退化为固定仓位策略**，5 种计票方式无差异。
2. **校准后事件信号主导更优。** 阈值降至绝对分数 3.0/2.0 后区分度恢复：纯事件计票（V4, candlestick/chanlun/turnover_anomaly ×2）显著优于当前 v2.5（事件×2+趋势×1）。解释：2026 弱市趋势信号负票泛滥（tr_neg 均值 1.13/日），参与计票反而劣化减仓择时。
3. **保护力上限：** 即便最优配置（thr_mid+V4），7 月仅改善 3.7-4.1pp（-16.6% vs BH -20.8%），DD -44% vs -53%；对急跌年（星环 -60% 级）无法提供完整保护。
4. **7 月保护弱于预期：** 阶段 3 触发率仅 ~1-1.7%（精确 5 大标志 end_count≥3 仅 1.62% vs 之前 tr_neg 近似 0.55%），急跌个股多在 2.5 阶段（0.8 仓）而非清仓。

## 建议
- **生产默认（保守）：** 保留 v2.5 计票权重（事件×2+趋势×1），但将阈值改为绝对分数并重测（thr_mid 3.0/2.0 为 2026 实证起点；thr_hi 5.0/3.0 更保守、与 v25_orig 差距最小）
- **候选升级：** 事件信号主导（V4）在 2026 显著更优，但**单一弱市年有事后选择嫌疑**，须跨年样本外验证（2015/2018/2022 弱市 + 2019/2020 强市）后再定案（→ BT-012）
- **阈值动态化：** 0.65/0.42 固定比例无 regime 适应性；可考虑按滚动 score 分位数校准
- **end_count 修正已落地：** 引擎已从 tr_neg 近似切换为精确 5 大标志（含 OBV 背离），后续回测以此为准

## 限制
- 样本仅 2026 一年（弱市/分化市），结论有 regime 依赖性
- 无交易成本、无涨跌停/停牌建模
- 趋势信号中 smc/factor_research/multi_factor/pair_trading/sector_relative 无 peer 时恒 0（与 no_cdmo 生产一致），真实持仓（CDMO 等有 peer）下趋势票更多
- thr_mid 为扫描最优之一，属于探索性证据而非验证性结论
