# BT-009: SELL_LADDER v2.2.1 完整持仓曲线 Walk-Forward 回测

## 假设
v2.2.1 (P0-1 OBV 真背离修复 + P1-4 完整 SMC 重写 + P1-6 ml_strategy 降级) 在 2026 年初跨板块行情中：
1. 通过完整持仓曲线模拟（而非仅看信号质量）证明方法可用
2. 通过双基准（买入持有 BH + 20% 移动止盈 MT20）证明价值
3. 通过 20 标的跨板块证明泛化能力

## 方法
- **标的池:** 20 只跨板块（科技 7 + 金融 4 + 消费 5 + 医药 2 + 新能源 2）
- **评估点:** 2026-01-01 起每周五 walk-forward（无未来函数）
- **每评估点:** 截至当日全部历史重算 13 信号 + 5 动能结束标志 + v2.2.1 阶段判定
- **完整持仓曲线:** 阶段1=100%, 阶段2=70%, 阶段2.5=60%, 阶段3=20%
- **交易成本:** 印花税 0.05% + 佣金 0.025%×2 + 滑点 0.1%×2 = 0.275%/次完整买卖
- **双基准:**
  - **BH (买入持有):** 信号无关，100% 仓位一直持有
  - **MT20 (20% 移动止盈):** 从最高点回撤 20% 即清仓出场（不回补）

## 结论
- **PARTIALLY_SUPPORTED（v2.2.1）** — 60% 跑赢 BH / 75% 跑赢 MT20，但 P0/P1 修复后阶段 1 几乎不可达（5% 触发率）

4. **SMC 信号权重:** 新完整 SMC 在 A 股日线上多数时点返回 0（结构信号稀疏），考虑降低其阈值或改为辅助观察

## Adversarial Review
- **最可能出错:** ① 阶段 2.5 占比 76% 本身是"无明确结论"的体现，可能导致仓位调整钝化；② MT20 的"不回补"实现是简化版，可能高估其优势；③ 完整持仓曲线模拟假设"每周评估日调仓"，但实盘中评估日可能错过最优调仓时机
- **最易被误读:** "v2.2.1 跑赢 BH 60%" → 错误！这是 20 标的的算术平均，未考虑资金权重；2026 行情是科技牛市，强趋势股全部跑输 BH 才是真实问题
- **Regime 依赖:** 若 2026H2 切换到单边熊市，v2.2.1 的下跌防守优势会扩大；若切换到强趋势，阶段 1 几乎不可达的问题会更突出
- **推荐重跑频率:** 每季度（尤其在 OBV/SMC 完整实现后首次重测）
