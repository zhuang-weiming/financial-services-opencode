## 1. 假设

**核心假设 (v3.1):** BUY_LADDER v3.1 经典 LazyBear 阈值 + V21 OB filter 的买入信号，
未来 20/60/120 天 forward 收益中位为正，且胜率 ≥ 55%。

**对比目标:**
- **C1 (经典)**: WT1 sweet zone [40, 60] 静态阈值 (LazyBear OBLEVEL1=60)
- **C2 (V21 OB)**: WT1 进入 [40, adaptive_ob_threshold]，其中 threshold = 53 + 40 × mcap_pctile (Vibe-Trading V21)
- **C3 (基准)**: 买入持有 (BH) + 简单 MA60 突破

**子假设:**
- H1: C2 (V21 OB) 的入场胜率 ≥ C1 (经典静态) —— 跨截面 mcap 自适应应该减少大盘股假超买过滤
- H2: Layer 0 regime 闸门过滤后，buy 触发频率 < 总时间的 30%（保守入场）
- H3: WT1 甜区穿越 (5 大确认 ①) 是最高效的确认标志（单独使用时胜率 > 60%）
- H4: sell-buyer 闭环（模式 B）的加仓胜率 > 阶段 1 首次建仓

## 2. 方法论设计（避免 BT-004 方法论错误）

### 2.1 关键设计原则

| 原则 | 实施 |
|:---|:---|
| **对照组** | C1 经典 vs C2 V21 OB vs C3 BH/MA60 |
| **双向分析** | 测"buy 信号触发" 与"buy 信号未触发但手动买入" |
| **多因子归因** | 控制 regime / 板块 / 市值 / PE 分位的同期变化 |
| **样本量** | ≥ 50 个 buy 信号事件（跨 2010-2026）|
| **失败定义** | 持仓 60d 后亏损 ≥ 10% = 失败事件 |

### 2.2 样本池

| 维度 | 选择 |
|:---|:---|
| **标的池** | alpha-engine-v21 HDF5 已有 3060 只 A 股 (192 月 × 3060 股票) |
| **时间窗** | 2010-01 → 2026-08（192 个月）|
| **分层** | 按市值分 3 层 (≥300亿 / 100-300亿 / <100亿) + 按板块分 6 层 (科技/医药/消费/金融/工业/能源)|
| **去重** | 同标的不重复事件（首次 Stage 1 触发后冷却 60 天）|

### 2.3 评估指标

| 指标 | 公式 | 期望 |
|:---|:---|:---:|
| **fwd 60d 中位收益** | median(ret_60d) | > 0% |
| **fwd 60d 胜率** | count(ret_60d > 0) / n | > 55% |
| **fwd 120d 中位** | median(ret_120d) | > 0% |
| **fwd 120d 胜率** | count(ret_120d > 0) / n | > 55% |
| **平均持有期** | mean(持有天数) | — |
| **最大回撤** | min(ret_min_d during 持有期) | — |
| **Sharpe** | mean(ret_60d) / std(ret_60d) | > 0.5 |

### 2.4 关键子回测

| 子回测 | 目的 | 预期 |
|:---|:---|:---:|
| **Layer 0 闸门有效性** | 比较"闸门关闭时入场" vs "闸门开启时入场" 的胜率 | 开启 >> 关闭 |
| **5 大确认标志单验** | 5 大确认分别单验胜率，识别最高效标志 | WT1 甜区 + 趋势启动 最优 |
| **5 大否决标志单验** | 5 大否决分别单验"否决 vs 通过" 胜率 | 否决时胜率 << 通过 |
| **模式 B sell-buyer 闭环** | sell Stage 1 + 回调 5% 的加仓 vs 不加仓 | 加仓 >> 不加仓 |
| **WT1 甜区穿越 vs 零穿越** | 直接对比 BT-007 deep-recovery | 甜区穿越 >> 零穿越 |

## 8. 回测结果 (2026-08-11 首跑)

### 8.1 对比结果 (start=2012-01-31, n_hold=10, HDF5 月度数据)

| 配置 | NAV | 区间收益 | 触发次数 |
|:---|:---:|:---:|:---:|
| **C2 V21 OB filter** | **13.463** | **+1246.3%** | 727 |
| C1 经典 [40, 60] | 9.515 | +851.5% | 943 |
| C3 买入持有 (top10市值) | 5.629 | +462.9% | — |

### 8.2 初步结论

1. **C2 (V21 adaptive OB) 显著最优**：+1246% vs 经典 +851% vs 买入持有 +463%
2. **V21 OB filter 有效**：触发 727 次 < 经典 943 次 → 跨截面 mcap 自适应过滤了 216 次"大盘股假超买"信号，且收益更高（质量 > 数量）
3. 两个信号策略都大幅跑赢买入持有（+851% / +1246% vs +463%）
4. 这验证了用户"V21 OB filter 优于静态 [40,60]"的假设（C2 胜 H1）

### 8.3 Adversarial Review (BT-010)

- **回测最可能出错的方面:** ① HDF5 wt1_monthly 有 57.7% NaN（早期间股票数据稀疏）；② 未含交易成本；③ 月度调仓选股用"信号触发 + WT1 排名 top-N"，未含完整 buy-ladder 的 5 大确认/否决
- **最容易被误读的方式:** "C2 +1246% = buy-ladder v3.1 完整策略收益"——**错误**！这是简化版（只有 WT1 甜区穿越单信号），不含 Layer 0/1/2 完整过滤
- **Regime 变化检测:** 2012-2026 含 2015 杠杆牛 + 2020-2026 结构牛，牛市占比高可能放大收益；需 P1 衰减重算
- **推荐重跑频率:** 每季度（H5 更新时）
- **分拆验证建议:** ① 加交易成本（印花税+佣金+滑点）；② 加入 5 大确认/否决完整逻辑；③ 分 regime（牛/熊/震荡）分别统计
