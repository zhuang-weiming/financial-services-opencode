## 4. 深度恢复模式 (Deep Recovery)

**触发条件:** WT1 60 个交易日前 < -30 → 当前 WT1 ∈ (0, 30] —— 当前正是此模式。

**样本:** 65 个事件 (2017-11 至 2026-08)，典型年份 2022-07 (17 events), 2024-10/11/12 (43 events)。

| 指标 | 数值 |

| 60d forward 胜率 | 51% |
| **120d forward 胜率** | **17%** (大输家) |

**典型近邻事件 (2024-10 至 2024-12):**
- 2024-10-24: WT1 -44 → +1.80 → 60dfwd **-18.03%**, 120dfwd **-17.08%**
- 2024-11-14: WT1 -32 → +20.5 → 60dfwd +13.06%, 120dfwd **-15.65%**
- 2024-12-04: WT1 -43 → +19.1 → 60dfwd +11.37%, 120dfwd **-6.70%**

**结论:** 历史模式**不乐观** — 深度恢复后 6 个月内大概率回踩 / 持平；6-12 个月后倾向负收益。

## 8. 风险与局限

1. **样本偏差:** 300725 仅 2017-11 上市 → 仅 ~8.5 年历史，"甜区"识别统计 power 有限
2. **HDF5 不兼容:** V21 score_v21 无法直接调用；本分析用单股 forward returns 替代
3. **regime 主观:** "防御熊"判断来自 framework，非量化 regime 检测
4. **单股均值/中位数差异:** 如 LAW-002，单股 high-WT1 区间少数 10x 反弹可能放大均值；本文已用 median
5. **Panel 截止 9 天差异:** 2026-07-31 vs 2026-08-10 — WT (N2=105) 维度影响 < 0.5 个 WT 点
6. **未计算 Deflated Sharpe Ratio:** 8 zone × 4 horizon = 32 假设 — 应做 Bonferroni 校正 (粗略: 任意 zone × 任意 horizon p-value × 32)
