# BT-021 — "IPO 热度 → 相关板块二级市场上涨" 机制检验

> **日期:** 2026-09-15
> **执行者:** backtest-builder（wealth-guide 派发）
> **触发:** 用户买入 563530 的论证"卫星/火箭 IPO 如火如荼 → 需要高人气 → 需要资金 → 股票需要大涨 → IPO 需要炒高"
> **假设:** A 股历史上，IPO 活动密集期（"科技 IPO 潮"）与相关板块（承销受益的券商 / 发行主体的科技军工）**未来**二级市场表现正相关（情绪外溢）
> **对照:** BT-006（2026-08-04）已在**个股层面**否定用户持仓的"科技 IPO 受益"（中银投行毛利率 −19.3%）；本回测检验**市场层面**机制
> **数据源:** akshare `stock_xgsglb_em`（新股申购，2010-2026，4,027 条）；申万一级行业指数 + CSI300（复用 BT-006 缓存）
> **复权口径:** 行业指数 = 官方价格指数；IPO 募资额单位 = 发行总数(万股) × 发行价格(元) = 万元
> **样本:** 2010-01 → 2026-07（月度，IPO 家数 vs forward 1m/3m/6m）
> **lookahead:** 无——t 月 IPO 家数（当月已知）对 t+1/t+3/t+6 月收益
> **免责声明:** 回测仅研究工具，不代表未来收益

---

## 一、方法

1. **IPO 强度:** 月度 IPO 家数（`stock_xgsglb_em` 申购日期）+ 3m/12m 滚动和；募资额为辅助。
2. **(A) 相关性:** IPO 月度家数 vs 各板块**同期**与 **forward 1/3/6m** 收益（Pearson r + t 检验）。
3. **(B) 分位事件研究:** 按 IPO 强度三分位，比较高 IPO 月 vs 低 IPO 月之后的 forward 收益。
4. **(C) 自然实验:** 2013 IPO 暂停（2012-11 → 2013-12，家数=0）期间的板块表现。
5. **子期稳健性:** 2010-2015 / 2016-2020 / 2021-2026。

## 三、结论

> **用户的"IPO 需要炒高 → 买入"论证，在 A 股历史上被反向证伪。**
>
> IPO 密集期之后，恰恰是相关板块（含承销受益的券商、含发行主体的科技/军工）forward 6 个月**跑输**的时期。
> 机制方向与用户所述相反：不是"IPO 需要炒高 → 板块涨"，而更接近 **"IPO 潮 = 市场过热/供给放大的晚期信号 → 均值回归 + 抽血"**。
> 国防军工（最贴近卫星主题）高 IPO 月 fwd6 中位 **−6.79%、胜率 31.5%** —— 最不利的一档。

## 四、局限与边界（诚实标注）

1. 检验的是**市场级 IPO 强度**，非"卫星/火箭专属 IPO 潮"（后者样本不足以单独统计）。
2. IPO 活动对市场条件**内生**（热市才多发 IPO）→ 本结果是**预测性负相关**，不支持"抽血"因果的**确证**。
3. 6 个月 forward 窗口月度重叠 → t 值被高估（有效独立样本 < n）；r 的**符号与量级**比 t 的绝对显著性更可信。
4. 2013 自然实验中多数板块数据缺失；"暂停期市场上涨"亦有其他解释（2013 创业板独立行情）。
5. **主张②（IPO 正在展开）本身部分成立**：科创板 3 家在审（蓝箭航天/中科宇航/微纳星空）+9 家辅导；
   但"2026 年 115 只新股中空间类 0 只" → **卫星 IPO 潮尚未发生**。

## 五、Adversarial Review

- **最可能出错的方面:** ① 内生性（IPO 潮↔市场热）使因果解读不可靠；② 重叠窗口高估显著性；③ 市场级 ≠ 主题级。
- **最容易被误读的方式:** "**IPO 是熊市信号 → 应该做空**" —— 过度解读。本回测只证"IPO 密集 → 相关板块 forward 6m 跑输"，
  未建立可交易的空头策略，也未排除"同期其他宏观因子"。
- **Regime 变化检测:** 注册制/全面注册制后（2021+）负相关反而更强（通信 −0.44、沪深300 −0.61）——机制未弱化。
- **推荐重跑频率:** 每年；或每轮 IPO 政策周期（收紧/放开）后。
- **分拆验证建议:** (1) 用 IPO **募资额**（供给冲击）替代家数；(2) 加入"IPO 上市首日涨幅"作为情绪变量；
  (3) 卫星/航天专属 IPO 事件研究（需未来样本积累）。
