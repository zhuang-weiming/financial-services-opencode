# BT-017 — 信心系数缩放仓位 vs 均匀 50% 仓位 (BUY_LADDER v4.0 sizing hypothesis)

- **日期:** 2026-09-01 (首跑)
- **执行者:** backtest-builder (BT-017/bt017_confidence_sizing.py)
- **假设 (用户提案 v4.0):** 用 `final_position% = base_weight(score) × ∏ confidence_factor_i` 替换 v3.1 固定 50% 首仓；floor=0.5% (venture)，cap=2×base，仅 5 大否决可归零。8 个候选因子各 0.5~1.5。
- **数据 (零新下载，除基本面一次抓取并缓存):**
  - 信号: BT-011 `signal_cache_v2.parquet` (16 信号, 200 池, 2024-10-08~2026-08-13, 89,845 行)
  - 价格: `data/market/daily/<code>*.csv` (200/200 覆盖, 900 bars)
  - regime: `data/market/daily/510300.csv` (CSI300 ETF MA60 — 与 buy_ladder Layer-0 同源)
  - 基本面: `results/fundamentals_raw.json` (akshare `stock_financial_abstract` ROE/资产负债率 FY2023-25 + `stock_zh_valuation_baidu` PB 3 年; 200/200 抓取成功)
- **样本期:** 2024-10-08 ~ 2026-08-13 (2025 牛 + 2026 弱, 与 BT-011~016 同窗)

## 方法

1. **计分 (BT-016 W_B):** score = 2·I(technical_basic>0) + 2·I(alpha_zoo>0) + 1·I(candlestick>0) + 1·I(ad_line>0), max 6；≥4 击球区 / ≥3 观察区。
2. **事件定义:** 每股每 60 交易日窗口内首个 score≥3 事件 (避免重叠仓位)。forward 20/60 日 close-to-close 收益；超额 = 事件收益 − 当日同池等权截面基准 (BT-013/014/015/016 惯例)。
3. **基线:** V1 均匀 50% (每个 ≥4 事件) + V0 0% / V2 100% 上下文；V3/V4 信心缩放；V5 均匀 50% 于 ≥3 事件 (与 V3 公平对比)；V6 简化 2 因子 (f1_sig × f6_trend)。
4. **8 因子操作化** (每个 0.5~1.5, 与 v4.0 提案一致):
   | # | 因子 | 操作化 | 覆盖 |
   |:-:|:--|:--|:-:|
   | f1 | 信号强度 | score 3/4/5/6 → 0.85/1.00/1.15/1.30 | 100% |
   | f2 | 基本面质量 | 年 ROE>10%→1.2; 0~10%→1.0; 亏损→0.6; 负债率>90%→×0.7 (PIT: 年报 4/30 截止映射 FY) | 100% |
   | f3 | 估值 | 滚动 252d PB 分位 <20%→1.2; 20-50%→1.0; 50-70%→0.9; >70%→0.8 | 99.6% |
   | f4 | 波动率 | 年化 vol<30%→1.1; 30-60%→1.0; >60%→0.7 | 99.3% |
   | f5 | 流动性 | 日成交额>5亿→1.1; 1-5亿→1.0; <1亿→0.8 | 100% |
   | f6 | 趋势质量 | ADX>30 且 WT1>0→1.2; ADX 20-30→1.0; ADX<20→0.8 | 99.9% |
   | f7 | regime | CSI300 ETF 收盘>MA60→1.2 / <MA60→0.8 (单代理, 见限制) | 100% |
   | f8 | 分析师主观 | 恒 1.0 (人工输入不可回测, 仅作为 discretionary overlay) | — |
5. **组合模拟:** 事件日收盘进场, 持有 20/60 交易日, 逐日盯市; 并发仓位按 raw weight 总和>100% 时 pro-rata 缩至 100% (无杠杆); 报告年化 Sharpe / max DD / 总收益。
6. **稳健性:** 2025 vs 2026 分年; cap/floor 网格 (1.5×~4×, 0.5%~2%); 事件聚类窗 20/40/60/90 日敏感性; 逐因子 OAT; bootstrap 95% CI。

## 结果

### A. 关键发现 1 — BT-016 正 α 几乎全部来自重复事件, 首入场事件 α≈0
| 事件类型 | n | α20 均值 | α20 t/p | α60 均值 | α60 t/p |
|:--|--:|--:|:--|--:|:--|
| **first-in-60d (真实买入点)** | 299 | −0.28% | −0.30 / 0.76 | −0.20% | −0.13 / 0.90 |
| repeat (同日持仓反复点亮) | 11,999 | +0.91% | +4.82 / <1e-5 | +1.28% | +4.21 / <1e-5 |

**BT-016 公布的 "W_B≥4 α60 +1.26%" 是对 12,163 个原始事件的等权平均, 其中 11,999 个是同一持仓的重复信号** — 与 first-entry 的 α≈0 不矛盾。本回测复现 BT-016 (原始全事件 α60 +1.24%, 与公布 +1.26% 一致), 但**去重后首入场事件的截面超额为零**。事件聚类窗 20/40/60/90 日敏感性均显示 first-entry α ≈ 0 (p>0.15 全不显著)。⚠️ 这直接影响 v3.1 "击球区 α60 +1.26%" 的可信度 — 该数字是持仓期间动量延续的度量, 不是"买入即赚"的证据。

- **V5 (均匀 50% 于 ≥3 事件) 20d Sharpe 0.839 为全场最高** — 扩大事件面比缩放仓位更有效 (但 60d 仅 0.405, 观察区信号只适合短持)。

**bootstrap (V4 完整 8 因子)**: 20d Δsw +0.17pp, 95% CI [−0.39, +0.75], 71.9% >0 (不显著); 60d Δsw −0.44pp, CI [−1.45, +0.60], 22.3% >0 (不显著)。
**bootstrap (V6 简化 2 因子)**: 20d Δsw +0.18pp, CI [−0.01, +0.38], 96.5% >0 (边际); 60d Δsw +0.28pp, CI [−0.03, +0.59], 96.2% >0 (边际, CI 含 0)。

### E. 稳健性
- **2025 vs 2026:** 所有 ≥4 变体 α60: 2025 −1.62% (牛, 负) / 2026 +7.35% (弱, 正) — 与 BT-014/016 "60d 持有溢价主要在弱市" 一致。V3/V5 (≥3): 2025 +1.92% / 2026 +0.48%。
- **cap/floor 网格 (1.5×~4×, 0.5%~2%):** size-weighted α 不变 (cap 从未触发: pos_conf max 0.941 < cap 1.0@base0.5; floor 0.5%/2% 无差异)。→ v4.0 的 floor/cap 机制在该因子取值范围内是惰性的。
- **聚类窗 20/40/60/90d:** first-entry α 全不显著 (p>0.15), 结论稳定。

## 结论 (Verdict)

1. **信心系数缩放 (v4.0 完整 8 因子) 未跑赢均匀 50%**: 组合 Sharpe 更差 (0.435/0.491 vs 0.469/0.508), size-weighted α 20d +0.17pp (不显著) / 60d −0.44pp (不显著)。**REJECTED (完整 8 因子版)。**
2. **仅 2 因子有正贡献 (f1_sig × f6_trend)**, 简化版 V6 在两个持有期 Sharpe 与总收益均优于均匀 50% (0.529/0.531 vs 0.469/0.508), bootstrap 96%+ 方向为正但 95% CI 含 0 → **边际支持, 需样本外确认**。
3. **f2_fund (ROE/负债) 与 f7_regime (MA60) 是负资产, 应从 v4.0 移除**: ROE 加权放大亏损事件; MA60 regime 与跨年 α 方向反向 (2025 牛 MA60 绿→1.2 放大负 α 事件; 2026 弱 MA60 红→0.8 缩小正 α 事件)。
4. **BT-016 "+1.26% α60" 需重新解读**: 该 α 来自 11,999 个重复事件 (持仓动量延续), 首入场事件截面 α≈0。v3.1 的击球区信号作为"买入点"没有可验证的截面超额; 它的价值更接近"持仓期间动量延续"而非"买入时点选择"。

## 对 BUY_LADDER v4.0 的建议

- **不建议部署完整 8 因子 v4.0。** 推荐保留 v3.1 均匀 50% 首仓作为默认, 或 (若想演进) 采用简化版:
  `final_position% = base(score) × f_sig(score) × f_trend(ADX, WT1)`, 其中
  - base: score=3 → 30%, score≥4 → 50%
  - f_sig: {3:0.85, 4:1.00, 5:1.15, 6:1.30}
  - f_trend: ADX>30 且 WT1>0 → 1.2; ADX 20-30 → 1.0; ADX<20 → 0.8
  - floor 0.5% / cap 2×base 保留 (惰性但无害)
- **把"扩大事件面"作为更高优先实验**: V5 (均匀 50% × ≥3 事件) 20d Sharpe 0.839 远高于 V1 (0.469), 说明观察区信号在 20d 持有下同样有价值 — 但 60d 崩塌 (0.405), 需短持纪律。
- **f8 分析师主观** 保留为人工 overlay (0.5~1.5), 不参与回测。
- 后续: 深熊样本 (2018/2022) + 含成本 + T+1 + Layer 0/1 闸门复测后再定案。

## 限制 (Adversarial Review)

- **最可能出错处:** ① 首入场 α≈0 依赖 60d 聚类窗与截面等权基准 — 换持有规则 (如"信号持续期间持有" = 重复事件口径) 结论不同, BT-016 的 +1.26% 恰恰是这种口径; ② f7 regime 仅用 CSI300 ETF MA60 单代理 (MCI/国家队无逐日可回测序列), 不能代表完整 Layer 0; ③ 基本面 ROE/负债为年报 PIT 映射 (每年 4/30 截止), 无中报/快报 — 事件日 1-5 月使用旧 FY 数据偏保守; ④ 无交易成本/滑点/T+1; ⑤ 2 年样本无深熊。
- **最容易被误读:** "V6 Sharpe 0.53 > V1 0.47 = 信心缩放赢了" → **错误**, V6 只用了 2 个因子 (信号强度+趋势), 完整 8 因子 V4 反而更差; "BT-016 α60 +1.26% 被推翻" → **不是推翻**, 是澄清口径 — 原数字是持仓期动量延续, 不是首入场择时 α。
- **Regime 变化:** 若未来补入 2018/2022 深熊, f4_vol/f6_trend 的弱市保护可能失效; MA60 regime 因子在牛转熊瞬间可能由负转正 (需重测)。
- **推荐重跑:** 每季度 + 缓存/数据更新后; 深熊样本 + 含成本组合级复测必做。
- **分拆验证:** ① V6 简化模型样本外 (2027 及以后); ② "信号持续期间持有" vs "首入场持有" 两种持仓口径的组合级对比; ③ f2/f7 在更大市值分层 (大盘 vs 小盘) 下是否仍为负贡献。
