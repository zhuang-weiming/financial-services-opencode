# BT-008: SELL_LADDER v2.0 方法有效性回测 — 2026 科技股行情 Walk-Forward

## 假设
sell-ladder v2.0 的 3 阶段判定（基于 5 强动能信号 + 5 动能结束标志）能在 2026 年初科技股行情中：
1. 上涨期保持阶段 1（不误杀上涨）
2. 见顶回撤时提前降级预警
3. 下跌期持续给卖出信号

## 方法
- **标的:** 6 只科技股（寒武纪 688256 / 中芯 688981 / 北方华创 002371 / 中际旭创 300308 / 海光 688041 / 韦尔 603501）+ 300725 药石 = 7 只
- **数据:** Sina API（900 bars，本地缓存 tech-pool/）
- **评估点:** 2026-01-01 起每周五，walk-forward 无未来函数（每点用截至当日全部历史重算 13 信号）
- **对照:** 信号给出后未来 5/10/20 交易日实际收益
- **变体:** v2.0（原始 5 强集合含 factor_research）+ v2.1（修复：multi_factor 补位）

### 两大发现

**发现 1（BUG，已修复）: factor_research 死灯**
- `calc_factor_research` 的 strong_momentum 条件 = `f2_ic > 0.5`，但全样本（7 标的 196 评估点）f2_ic 实测范围 **-0.17 ~ +0.10**（max +0.102）
- → 5 强信号实际只有 4 盏灯可能亮 → **阶段 1（要求 5/5）永远不可能触发**
- v2.0 全标的阶段 1 = 0/196（0%）
- **修复:** 5 强集合 factor_research 移除、multi_factor 补位（点亮率 57%）+ calc_multi_factor 补 strong_momentum 字段
- v2.1 阶段 1 恢复可达（北方华创 10/28、药石 7/28）

**发现 2（阈值问题，待修复）: 阶段 3 过度敏感 → 踏空主升浪**
- 阶段 3 首触发日全部超前实际最高点 64-115 个交易日（如北方华创 2/13 触发，实际顶 7/1）
- 阶段 3 后 fwd20d 中位数：4/7 标的为正（海光 +23.2%、中际旭创 +11.6%、北方华创 +8.6%）
- 最贵踏空：中芯 4 月 end=3 时 fwd20d +36.6%；寒武纪 4 月阶段 3 后 +82%
- 唯一正确识别：韦尔（单边阴跌 -31%，22/28 评估点在阶段 3，fwd20d 中位 -4.9%）

### 有效部分（方法成立的地方）
- **阶段 1 在强趋势中正确持有:** 北方华创 5-7 月 strong 5/5 阶段 1（期间 +11.6%/+33.2%），中际旭创 5-6 月阶段 1（+33.2%），中芯 5 月阶段 1（+5.9%）
- **阶段 2→3 降级在见顶后正确:** 中际旭创 7 月阶段 2（fwd -19.2%）、寒武纪 7 月阶段 2（fwd -18.3%）
- **5 动能结束标志 end=0 是持有前提:** 所有阶段 1 时点 end=0

## 结论
- **REJECTED（v2.0 原版不可用）** — factor_research 死灯导致阶段 1 永不触发，方法结构性失效
- **PARTIALLY_SUPPORTED（v2.1 修复版）** — 阶段 1 持有有效（上涨期不误杀），但阶段 3 阈值过敏感导致主升浪前夜踏空；下跌识别有效（韦尔全程正确）
- **修复建议（v2.2）:** ① 阶段 3 需连续 2+ 周确认（防抖动）；② 阶段 3 触发时 fwd20d 为正的标的，应结合 end_count ≥ 3 才允许大幅减仓（避免单周 strong≤2 就减）；③ 阶段 3 后首个 fwd20d 为正时回退阶段 2（自适应确认）

## v2.2 定案章节（2026-08-10 追加）: 分级计票 + 权重网格扫描

### 设计
用户假设：candlestick/chanlun/ml-strategy 是**事件信号**（明确买卖点），趋势信号只是方向判定 → 事件信号应加权 2x/3x。用回测验证。

**v2.2 分级计票:**
- 事件信号 (×2 票): candlestick, chanlun, ml_strategy
- 趋势信号 (×1 票): alpha_engine_v21, technical_basic, ichimoku, smc, alpha_zoo, multi_factor
- 辅助观察 (0 票): harmonic, pair_trading, volatility, factor_research
- score = 2·event_pos + 1·trend_pos − 2·event_neg, max=12
- 阶段阈值 (按 max 比例): 阶段1 ≥ 0.75·max, 阶段3 < 0.42·max
- 阶段3 追加条件: end_count ≥ 3 共振才大幅减仓，否则阶段 2.5 观察（不恐慌清仓）

**结论: 事件×2/趋势×1 是最优点** — 用户直觉被回测证实。
- ×2: 阶段3踏空代价 7.03% → 1.71% (-76%)，阶段1交出质量与×1持平
- ×3: 过度 — 阶段1质量崩 (0.68%)，688981/688041/300725 阶段1期间 fwd20d 转负（错过主升）

## Adversarial Review
- **最可能出错的方面:** ① weekly 评估点 + 单周判定抖动大（阶段 3 早触发的部分原因是单点采样）；② tech-pool 900 bars 数据从 2022-11 起，2026 年评估点有足够 warmup 但信号依赖的 EMA 长度受限；③ fwd_20d 用"未来真实数据"仅评估用，未模拟信号触发后的实际持仓动作（如阶段 3 减 70% 后的资金曲线）
- **最容易被误读的方式:** "阶段 3 后 fwd20d 为正 = 方法没用" — 错误！阶段 3 的 t+0 收益分布只是预警质量指标；方法的价值在于"阶段 1 持有 + 阶段 3 减仓"的组合，需模拟完整持仓曲线才能判定
- **Regime 变化检测:** 若 2026H2 A 股切换为单边熊市（阶段 3 高频出现），本回测"阶段 3 过早"结论可能反转（预警会变值钱）；反之若更强牛市，阶段 1 持有价值更大
- **推荐重跑频率:** 每季度（或 v2.2 阈值修复后立即重跑对比）
- **分拆验证建议:** (1) 模拟完整持仓曲线（阶段1=100%、阶段2=减20-40%、阶段3=减70-100%）对比买入持有；(2) 阶段 3 触发加入"连续确认周数"参数扫描；(3) 扩大标的池到 20+ 只（含下跌股）增加统计功效
