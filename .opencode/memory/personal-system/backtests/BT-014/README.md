# BT-014 — BUY_LADDER 买入分原型回测 (绝对阈值 V_W 弱市分 / V_B 牛市分)

- **日期:** 2026-08-13 (首跑)
- **执行者:** wealth-guide (P1 路径, bt014_buy_score_proto.py)
- **动机:** BT-013 证明旧阈值 0.65/0.42×max 两年零触发 (锁死) + 权重倒挂 → 用数据重建可落地的买入分
- **数据源 (零新下载):** BT-011 `signal_cache_v2.parquet` (200 池) + `data/market/daily` 价格
- **样本期:** 2024-10-08 ~ 2026-08-13 (89,845 obs; 2025 牛 + 2026 弱)
- **设计 (BT-013 数据驱动):**
  - **弱市买入分** `score_w = Σ I(sig>0)` for {**alpha_zoo, technical_basic, candlestick, ad_line**} — 2026 全部显著正 α
  - **牛市买入分** `score_b = 2·I(alpha_zoo>0) + I(technical_basic>0)` — 2025 仅 alpha_zoo 显著正 α
  - 阈值扫描 thr ∈ {1,2,3,4}; 事件研究同 BT-013 (未来 20/60 日 log 收益 vs 当日同池截面基准)
- **方法:** 触发日 (code,date) score≥thr → α20/α60/胜率/t/p; 分 2025/2026/全期

## 结果

### 有效性 (α20/α60, 全部显著正, 无锁死)

| score | thr | 2026 α20 | 2026 α60 | 2026 t/p | 触发频次(年/池) | 2025 α20 | 全期 α20 |

\* 2025 score_w thr=3 α60 = −0.44% (负, 效应 60 日不延续) — 牛市买入分 20 日有效但 60 日回吐

### 单调性与稀缺度

- **α 随 thr 单调增强** (score_w: thr1 +0.66% → thr2 +1.69% → thr3 +3.09%) — 信号协同条件有效
- **可达**: thr2 每月 2.4 次/池; thr3 每月 0.5 次/池 — 稀缺但可统计 (对比旧系统 0 次/两年, 彻底解锁)

## 结论

1. **绝对阈值定案**: 固定比例阈值 (0.65/0.42×max) → **绝对阈值 thr≥2 (观察) / thr≥3 (高确信加仓)**。触发不再锁死, 且严格正 α。
2. **双买入分成立 (对称 sell 侧双分数, 但买侧趋势类信号主导)**:
   - 弱市 `score_w` (4 信号等权): 2026 α60 +4.49% (thr2) / +6.44% (thr3)
   - 牛市 `score_b` (alpha_zoo 双权): α20/α60 跨年为正
3. **多因子修正**: `multi_factor` 生产实测 31.6%正/44.7%负 (活跃) — BT-011 缓存置零是口径误杀; 其事件 α 未经验证 → 列为新候选
4. **生产侧修复清单 (匹配 BT-013 INDEX Adversarial)**: ① calc_sector_relative 调用补传 ticker (buy_ladder.py:830); ② SECTOR_ETF_MAP_LOCAL 需扩表 (现仅 20 代码); ③ smc 确定性 0%+lookahead → 移出计票 (或换周线验证); ④ pair_trading 占位 0 → 移除

## 局限 (Adversarial Review)

- **最可能出错处:** ① 事件 α 未含 Layer 0 regime 闸门 & Layer 1 筛选 (buy 侧实际还有这两道门, 会进一步降频/精选); ② 无交易成本/滑点/T+1; ③ 仅 2 年 (2025/2026), 无深熊样本; ④ 2025 牛市 α60 转负提示"牛市买入分 60 日持有溢价弱" — 可能适合 20 日短持而非中线
- **最容易被误读:** "score_w thr3 α60 +6.44% = 买入必赚" → **错误**, 这是截面超额 (跑赢同池), 且为 20-60 日统计期望非个股保证
- **Regime 变化:** 若补入 2018/2022 深熊, technical_basic/ad_line 弱市信号可能失效 (熊市所有反弹信号都可能负 α) → 需深熊样本再验
- **推荐重跑:** 每季度 + 缓存/数据更新后; 补历史年份后必重跑
- **分拆验证:** ① 加 Layer 0 解锁期过滤重测 (buy 天然优势); ② multi_factor 纳入 cache 重算后验证其 α; ③ 深熊样本外; ④ 含交易成本的组合级回测 (非事件研究)

## 5-Why 交叉

- 与 BT-011/012/sell 侧完全同构方法论: 事件研究 → 绝对阈值 → 双分数. 买侧唯一差异: 有效信号集中在**趋势/动量类** (LAW-001 动量延续), 而非 sell 侧事件类.
- 结论最薄弱环节: 2 年样本 + 截面基准未风险调整 → 排序/方向可信, 绝对 α 大小需组合级复测.
