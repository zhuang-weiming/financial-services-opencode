## 局限 (Adversarial Review)

- 无成本/滑点/T+1; 截面基准未风险调整; 2 年样本无深熊
- **最有可能被误读**: "α60 +1.26% 全期" 是**跑赢同池 200 只的截面超额**, 非组合绝对收益; 月 2.5 次/池 指"某池某日出现可买信号", 非强制交易频率
